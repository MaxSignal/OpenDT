# 24 D2 戦闘

## この章の範囲

RPGツクール Dante98 II（D2）の戦闘処理全体を扱う。

- 戦闘の呼出し規約（引数・戻り値・呼出し元が前後でする処理・戦闘BGM）
- 戦闘で参照するデータ（敵レコード 0x50 バイト・敵グループレコード 0x16 バイトの全フィールド、MAGIC.DAT / ITEM.DAT / PLAYER.DAT のうち戦闘が参照するフィールド、敵画像 EGD・戦闘背景 EBD、WORD.DAT の戦闘用文言）
- 戦闘開始（トランジション・背景・敵画像・敵配置）、戦闘者データの初期化と書き戻し
- 画面レイアウト・カーソル選択・演出（点滅・消滅・踏み込み・揺れ）とフレーム数
- コマンド入力、敵 AI、混乱、オートバトル AI、行動順、ラウンド処理
- 通常攻撃・魔法・アイテム・防御・ため・逃走の計算式とメッセージ
- 勝利（経験値・お金・ドロップ・レベルアップ）、敗北、逃走
- 乱数を引く順序と回数、ビルド差分

## 1. 用語・記法

### 1.1 戦闘者スロット

戦闘中の全キャラクタは **10 個の戦闘者スロット**に置かれる。

| スロット | 内容 |
|---|---|
| 0〜4 | 味方。パーティの並び順（パーティ人数を超えるスロットは空） |
| 5〜9 | 敵。敵グループの順（敵数を超えるスロットは空） |

空スロットは「生存していない・全数値 0」の戦闘者として扱われる（行動順の計算でも 10 スロット全部を走査する）。

以下「敵 i」は敵の 0 始まりの番号（スロット = i + 5）。

### 1.2 状態番号

| 番号 | 状態 | 備考 |
|---|---|---|
| 0 | 毒 | 戦闘後も残る |
| 1 | 暗闇 | 戦闘中のみ |
| 2 | 沈黙（魔法封じ） | 戦闘中のみ |
| 3 | 混乱 | 戦闘中のみ |
| 4 | 睡眠 | 戦闘中のみ |
| 5 | 麻痺 | 戦闘後も残る |
| 6 | 気絶（戦闘不能） | 「生存フラグ」で表す。状態配列には持たない |

### 1.3 効果ビット番号（MAGIC.DAT の効果ビット・敵の耐性の添字）

MAGIC.DAT の 0x14〜0x16 の 3 バイトを「効果ビット」とし、ビット番号 n は **バイト 0x14 + (n ÷ 8) の、最上位ビットから数えて (n mod 8) 番目のビット**（すなわちマスク 0x80 を n mod 8 だけ右シフトした位置）とする。

| ビット | 攻撃型魔法（種別2/3）での意味 | 補助型魔法（種別0/1）での意味 | 敵耐性の同じ添字の意味 |
|---|---|---|---|
| 0 | HP ダメージ | HP 回復 | HP/MP ダメージ倍率 |
| 1 | MP ダメージ | （効果なし） | （未使用） |
| 2〜7 | 状態 0〜5 を付与 | 状態 0〜5 を回復 | 状態 0〜5 の付与率補正 |
| 8 | 即死（状態6付与） | 蘇生 | 即死の付与率補正 |
| 9 | 吸収（HP/MP ダメージを術者が得る） | — | （未使用） |
| 10〜13 | 攻撃力・防御力・精神力・素早さを下げる | 同 4 能力を上げる | 能力低下の成功率 |
| 14〜19 | 属性 1〜6 | — | 属性 1〜6 の倍率 |
| 20 | 自爆（術者 HP 依存ダメージ、使用後術者は気絶） | 同（使用後術者は気絶） | — |
| 21 | 防御無視 | — | — |
| 22, 23 | 未使用 | | |

### 1.4 耐性コード

敵の耐性は 20 項目（添字 0〜19、上表）各 2 ビットのコード。

| コード | 名称 | HP/MPダメージ・属性 | 状態付与率 | 能力低下成功率 |
|---|---|---|---|---|
| 0 | 普通 | ×1 | ±0 | 90% |
| 1 | 耐性 | ÷2 | −30 | 60% |
| 2 | 無効 | 0 | 0%（固定） | 0% |
| 3 | 弱点 | ×2 | +20 | 100% |

味方の耐性は、防具類（鎧・盾・兜・装飾品）の属性ビットに対応する属性（添字 14〜19）だけがコード 1（耐性）になり得て、他はすべて 0。

### 1.5 能力値

戦闘者は 4 能力（0 攻撃力・1 防御力・2 精神力・3 素早さ）について「基準値」と「現在値」を持つ。戦闘開始時は両方同じ値。能力上下魔法は現在値だけを変える。

### 1.6 時間の単位

- **フレーム** = 1 VSYNC（実時間で表示を進める速さは 56.4Hz。ミリ秒の待ちを換算するときだけ 56.42Hz を使う。→ 01章・21章）
- **待ち n 単位** = n × 7 フレーム。待ち開始時点で SHIFT が押されていれば n × 3 フレーム（以後 SHIFT を離しても途中で変わらない）。
- **キー待ち（戦闘用）**: SHIFT が押されていれば「待ち 3 単位」（SHIFT 押下中なので 9 フレーム）で終わる。押されていなければ、全キーが離されるのを待ってから何かのキーが押されるまで待ち（この待ちの間、ポーリング 1 回ごとに乱数を 1 回空引きする → 01章/23章の「キー待ち」と同じ）、その後さらに全キーが離されるまで 1 フレームずつ待つ。

### 1.7 効果音

本章で「効果音 n」と書くものは、エンジンの効果音要求に番号 n を渡すことを指す。02 章の効果音要求の番号（SOUND.DAT の `@` レコード番号）では **n + 10** を要求する（→ 02章 §5.3、22章 §6.9 と同じ規約）。戦闘で使う番号:

| n | 用途 |
|---|---|
| 1 | カーソル移動（汎用選択） |
| 2 | 決定 |
| 3 | キャンセル |
| 4 | 味方の通常攻撃開始 |
| 5 | 敵の通常攻撃開始 |
| 6 | HP ダメージ（吸収以外） |
| 7 | 攻撃回避（ダメージ 0） |
| 魔法の効果音番号 | 魔法発動演出（MAGIC.DAT 0x23） |

### 1.8 乱数

乱数は → 01章の乱数生成器（Borland C 互換の線形合同法：状態 = 状態 × 0x015A4E35 + 1（32 ビット）、出力 = 状態の上位 16 ビットの下位 15 ビット、0〜32767）。本章で「乱数 % m」は出力を m で割った余り。乱数を引く箇所・条件・順序は本文に正確に書き、§17 にまとめる。

### 1.9 整数演算

特記しない除算はすべて **0 方向への切り捨て**（負数も 0 方向）。「16 ビット符号付きに切り詰め」と書いた箇所は、積を下位 16 ビットに切り詰めて符号付き（−32768〜32767）として扱ってから次の演算をする（元実装の挙動を再現するため）。

## 2. 戦闘で参照するデータ

### 2.1 ENEMY.DAT

ENEMY.DAT は「敵レコード 0x50 バイト × 256」（オフセット 0x0000〜0x4FFF）に続いて「敵グループレコード 0x16 バイト × 256」（オフセット 0x5000〜0x65FF）、合計 0x6600 バイト。全サンプルゲームでこのサイズであることを確認済み。ファイルが短い場合、足りない部分は 0 として扱う。

#### 2.1.1 敵レコード（0x50 バイト、敵番号 n はファイル先頭から n × 0x50）

| オフセット | サイズ | 型 | 意味 | 備考 |
|---|---|---|---|---|
| 0x00 | 17 | 文字列 SJIS | 敵の名前 | 0 終端（17 バイト全部使えば終端なし） |
| 0x11 | 1 | u8 | 画像番号 | EGD ファイル番号（§2.5） |
| 0x12 | 4 | u32LE | 経験値 | |
| 0x16 | 4 | u32LE | お金 | |
| 0x1A | 4 | u32LE | 最大 HP | 戦闘開始時の HP も同値 |
| 0x1E | 2 | i16LE | 最大 MP | 戦闘開始時の MP も同値。**9999 以上は MP 無限**（§12.8） |
| 0x20 | 2 | i16LE | 攻撃力 | |
| 0x22 | 2 | i16LE | 防御力 | |
| 0x24 | 2 | i16LE | 精神力 | |
| 0x26 | 2 | i16LE | 素早さ | |
| 0x28 | 5 | 2ビット×20 | 耐性 | 添字 i のコードは バイト 0x28 + (i ÷ 4) を右へ (6 − 2 × (i mod 4)) ビットシフトした下位 2 ビット（各バイトの上位 2 ビットが小さい添字）。添字の意味は §1.3、コードは §1.4 |
| 0x2D | 1 | u8 | 未使用 | 全サンプルで 0 |
| 0x2E | 1 | u8 | 逃走成功率（%） | 味方が逃げるときの成功率。0 なら逃げられない（§14） |
| 0x2F | 1 | u8 | アイテムドロップ率（%） | |
| 0x30 | 1 | u8 | ドロップアイテム番号 | 0xFF = なし |
| 0x31 | 4 | u32LE | 変身 HP 閾値 | HP がこの値以下になると変身（§12.3） |
| 0x35 | 1 | u8 | 変身先の敵番号 | 0xFF = 変身しない |
| 0x36 | 16 | (u8,u8)×8 | 行動テーブル | 8 項目。各項目は（種別, パラメータ）。下表 |
| 0x46 | 1 | u8 | 大きさ区分 | 0 = 小（EGD_ENS）、0 以外 = 大（EGD_ENL）。どちらのフォルダから読むかだけに使い、実際の大きさは EGD ファイル側の値で上書きされる（§4.2） |
| 0x47 | 9 | — | 未使用 | 全サンプルで 0 |

**行動テーブルの種別**

| 種別 | 意味 | パラメータ |
|---|---|---|
| 0 | 通常攻撃 | 不使用 |
| 1 | 魔法 | 魔法番号 |
| 2 | 防御 | 不使用 |
| 3 | 逃走（敵が逃げる） | 不使用 |
| 4 | 2 回攻撃 | 不使用 |
| 5 | ため（次の攻撃の威力を上げる） | 不使用 |
| 6 | 毒攻撃（毒を 100% 付与する通常攻撃） | 不使用 |
| 7 | フラグ A：補助魔法の評価で自分だけを対象とみなす（§9.4） | 不使用 |
| 8 | フラグ：復活する（倒されても一定ターン後に全快で復活、§11.2） | 不使用 |
| 9 | フラグ：リーダー（この敵がいなくなると残りの敵も全滅扱い、§11.5） | 不使用 |
| 10 | フラグ：会心率 30%（無いとき 5%） | 不使用 |
| 11 | フラグ：命中率 70%（無いとき 95%） | 不使用 |
| 12 | フラグ：1 ターンに 2 回行動 | 不使用 |
| 13 | フラグ：1 ターンに 3 回行動（12 と両方あれば 3 回） | 不使用 |
| 14 | カウンター：物理攻撃を受けたら魔法で反撃 | 反撃魔法番号 |
| 15〜20 | カウンター：属性 1〜6 の攻撃（武器属性または魔法属性）を受けたら魔法で反撃 | 反撃魔法番号 |
| 21（0x15） | 空き | — |
| 22 以上 | 無視 | — |

戦闘開始時、8 項目を先頭から順に見て、種別 0〜6 は「行動リスト」に順に追加（行動リストの件数 = 0〜8）、種別 7〜20 は対応するフラグを立てる（種別 14〜20 はさらに反撃魔法番号を記録）。同じ種別のフラグ/カウンターが複数あれば後のパラメータが有効。行動リストに入らなかった種別は行動選択の対象にならない。

#### 2.1.2 敵グループレコード（0x16 バイト、グループ番号 g はファイル先頭から 0x5000 + g × 0x16）

| オフセット | サイズ | 型 | 意味 | 備考 |
|---|---|---|---|---|
| 0x00 | 17 | 文字列 SJIS | グループ名 | 戦闘では使わない（エディタ用） |
| 0x11 | 5 | u8×5 | 敵番号 1〜5 | 0xFF = 空き。空きを詰めて、残った順に敵 0, 1, … とする |

例（Ring）: グループ 1 の 5 バイトは FF FF 01 FF FF → 敵は 1 体（敵番号 1）。

### 2.3 ITEM.DAT（戦闘で参照するフィールド、1 レコード 0x28 バイト）

| オフセット | サイズ | 型 | 意味 | 該当種別 |
|---|---|---|---|---|
| 0x00 | 16 | 文字列 | アイテム名 | 全 |
| 0x11 | 1 | u8 | 種別：0 大事な物、1 武器、2 鎧、3 盾（腕）、4 兜、5 装飾品、6 単体回復、7 全体回復、8 魔法効果、9 魔法習得、10 スイッチ | 全 |
| 0x17 | 1 | u8 | 消耗フラグ（0 以外なら使うと 1 個減る） | 6〜8 |
| 0x18 | 1 | u8 | 発動する魔法番号 | 8 |
| 0x19 | 1 | u8 | 武器：攻撃属性ビット（ビット0〜5 = 属性1〜6） / 鎧・盾・兜・装飾品：耐性属性ビット（同） | 1〜5 |
| 0x19 | 2 | i16LE | HP 回復量（0x19 は上の属性バイトと重なる） | 6, 7 |
| 0x1B | 2 | i16LE | MP 回復量 | 6, 7 |
| 0x1D | 1 | u8 | 状態回復ビット：ビット0〜5 = 状態0〜5 を回復、ビット6（0x40）= 蘇生 | 6, 7 |
| 0x22 | 1 | u8 | 命中率（%） | 1（武器） |
| 0x23 | 1 | u8 | 追加効果ビット：ビット0 毒、1 暗闇、2 沈黙、3 混乱、4 麻痺、5 即死（睡眠は付与できない） | 1 |

### 2.5 敵画像ファイル（EGD）

- 小さい敵: `EGD_ENS/ENS%03d.EGD`、大きい敵: `EGD_ENL/ENL%03d.EGD`（%03d は画像番号、10 進 3 桁ゼロ埋め）。どちらを読むかは敵レコード 0x46 で決める。

| オフセット | サイズ | 意味 |
|---|---|---|
| 0x00 | 48 | パレット 16 色 × (R, G, B)、各バイトの下位 4 ビットが値（0〜15） |
| 0x30 | 1 | 大きさ：0 = 小（80×96 ドット）、0 以外 = 大（160×128 ドット） |
| 0x31 | 1 | 未使用 |
| 0x32 | 幅/8 × 高さ × 5 | 5 枚のプレーンを順に：マスク、B（色ビット0）、R（色ビット1）、G（色ビット2）、輝度 I（色ビット3）。各プレーンは 1 行 (幅/8) バイト × 高さ行、行優先、各バイトの最上位ビットが左端 |

- ファイルサイズ: 小 = 50 + 10×96×5 = 4850 バイト、大 = 50 + 20×128×5 = 12850 バイト（サンプルで確認）。
- 小大はファイル側（0x30）の値が優先する。ファイルが無い/50 バイト未満なら、その敵の画像は空（全プレーン 0 = 何も描かない）で、大きさは「小」扱い。このときパレットは変更しない（§4.2 手順 6 のパレット上書きも起きない）。ファイルが短く途中までしか無ければ、足りないバイトは 0。
- マスクのビットが 1 のドットが不透明（§6.7）。

### 2.6 戦闘背景ファイル（EBD）

- `EBD_BKG/BKG%03u.EBD`（%03u は戦闘背景番号）。
- 先頭 48 バイトがパレット（EGD と同形式）、続いて 4 プレーン × 0x2800 バイト（1 プレーン = 80 バイト × 128 行、プレーン 0〜3 が色ビット 0〜3）。合計 41008 バイト（サンプルで確認）。
- 画面の y = 104〜231（横は全幅 640）に描く。
- ファイルサイズが 41008 バイト未満（無い場合を含む）なら何も描かず、パレットも変えない。

## 3. 呼出し規約

### 3.1 引数と戻り値

戦闘は次の 2 つの引数で呼ばれる。

1. **敵グループ番号**（0〜255）
2. **ゲームオーバーモード**：0 以外なら、全滅時にタイトルへ戻る。0 なら全滅しても戦闘から「敗北」を返して呼出し元に戻る。

戻り値：1 = 勝利、2 = 逃走成功、3 = 敗北（ゲームオーバーモード 0 のときのみ返る）。

呼出し元:

| 呼出し元 | ゲームオーバーモード | 備考 |
|---|---|---|
| ランダムエンカウント（→ 21章） | 1 | |
| イベントの通常戦闘コマンド（→ 22章） | 1 | イベント消去指定付きの変種あり |
| イベントの敗北許可戦闘コマンド（→ 22章） | 0 | 敗北時、呼出し元が先頭メンバーの麻痺を解き、HP 0 なら HP 1 で生き返らせる |

**戦闘中の STOP（テストプレイのイベント中断）**：戦闘中は状態ブロックの「イベント実行中」フラグが常に 0 である（ランダムエンカウントではもともと 0。イベントの戦闘コマンドは戦闘を呼ぶ直前にフラグを 0 にし、戻ってから 1 に戻す → 22 章の戦闘コマンド、22 章 §6.3）。STOP 検査はこのフラグが 1 のときだけ中断を起こすので、**戦闘の途中で STOP によりイベントが中断されることはない**。戦闘内のカーソル選択・一覧・キー待ちが STOP 検査を行うかどうかは結果に影響しない（行わない実装でよい）。STOP キーを押し続けていれば、戦闘から戻ってイベントの次のコマンドに進む時点の STOP 検査で中断される。（v1.1 で追記）

戦闘背景番号は呼出し元が状態ブロックの「戦闘背景番号」に設定しておく（エンカウントなら現在地のチップに対応する番号、イベントなら指定値または 0xFFFF で現在地のチップから。→ 21/22章）。

### 3.2 呼出し元が前後に行う処理（戦闘BGM）

1. 戦闘前：マップの戦闘BGM名（マップヘッダ 0x0D の 8 文字、または既定）と現在のBGM名を先頭 8 文字で比較し、異なれば戦闘BGMの再生を要求する。同じなら何もしない（BGMは途切れず続く）。
2. 戦闘を実行する。
3. 戦闘後：マップのチップ・キャラ画像を読み直し、プレイヤー/乗り物の画像を読み直し、勝利かつイベント消去指定ありならそのイベントを消去し、イベントページを更新し、テキスト層をフィールド用マスクに戻し、色調（トーン種別）を再適用（パレット復元）、フィールドを再描画し、1 フレーム待って明るさ 100% で表示する。
4. 戦闘BGM名と現在BGM名が異なれば、現在BGMの再生を要求する（フィールドBGMに戻る）。

勝利ファンファーレ等の戦闘専用の曲切替えは戦闘処理自体には無い。

## 4. 戦闘開始

### 4.1 全体の手順

1. 状態ブロックの「エンカウント歩数カウンタ」を 0 にする。
2. アイテム一覧のページ・カーソル位置を 0 に、全 12 キャラクタの魔法一覧のページ・カーソル位置を 0 にする（戦闘中の一覧は常に先頭から始まる）。
   - 正確には「**戦闘ごとに**先頭から始まる」。0 にするのはこの戦闘開始時の 1 回だけで、戦闘中は 23 章 §2.3 の記憶（所持品用 1 組、魔法はキャラクタ番号ごとに 1 組）がそのまま使われ、ターンをまたいでも、同じターン内で別のキャラが開いても保たれる（所持品の記憶は全キャラ共有、魔法の記憶はスロットではなくキャラクタ番号ごと）。戦闘後もこの値が残るが、フィールドメニューは開くたびに 0 に戻すので見た目には影響しない（23 章 §3.2）。（v1.1 で修正）
3. 戦闘画面の準備（§4.2）。
4. 待ち 4 単位。
5. オートバトルを解除状態にする。
6. この時点で「敵全滅判定」（§11.5）が真なら（敵が 0 体のグループなど）、書き戻し（§5.3）→ 勝利処理（§15.1）→ 後始末（§4.5）をして「勝利」を返す。
7. 戦闘メインループ（§7）へ。

### 4.2 戦闘画面の準備

1. 敵グループレコードから 0xFF 以外の敵番号を順に取り出し、敵数を決める（最大 5）。
2. **トランジション**（§4.3）。
3. **背景描画**：戦闘背景番号の EBD を読み、パレットを EBD のものにし（まだ表示はしない：明るさ 0% のまま）、y = 104〜231 に描く（§2.6）。
4. この時点の画面全体を「背景コピー」として保存する（スプライト消去の復元元）。
5. 全 10 スロットを空にし、味方スロット 0〜(パーティ人数−1) をパーティの並び順に初期化（§5.1）、敵スロットを敵番号順に初期化（§5.2）。
6. 敵 0 から順に EGD を読む（§2.5）。**EGD を読むたびに、そのファイルのパレットが戦闘パレットになる**（上書き）。結果として、最後に読んだ敵のパレットが戦闘中のパレットになり、背景 EBD のパレットは（敵が 1 体でもいれば）残らない。各敵の大きさ区分を EGD の値で置き換える。
7. **入りきらない敵の削除**：合計幅 = Σ（大なら 168、小なら 104）。「合計幅 − 24 ≥ 601」である間、最後の敵を削除して（スロットを空にし、敵数を 1 減らす）再計算する（つまり 合計幅 ≤ 624 になるまで）。削除された敵の画像も手順 6 で読まれてパレットは適用済みである点に注意。
8. **敵配置**：
   - h = −((合計幅 − 24) ÷ 2)
   - x = h + 320。x が 8 の倍数でなければ x = h + 316。
   - 敵 0 から順に：小なら位置 (x, 136)、x に 104 を足す。大なら位置 (x − 8, 104)、x に 168 を足す。
   - 位置は画像左上。描画時の横位置は 8 ドット単位に切り捨てる（§6.7）。
   - 例：小 1 体 → (280,136)、大 1 体 → (240,104)、小 3 体 → (176,136), (280,136), (384,136)。いずれも中心は x = 320。小の画像の間隔は 24 ドット。
9. ウィンドウを描く：メッセージウィンドウ (80,0) 480×96、コマンドウィンドウ (0,240) 120×144、敵名ウィンドウ（§6.4、敵名も描く）、パーティウィンドウ（§6.3、全行通常表示）。
10. メッセージ行 0 に WORD.DAT 0x4A0（戦闘開始メッセージ）を表示。
11. 敵 0 から順に画像を通常表示モードで描く。
12. テキスト層を「メニュー用マスク」にする：テキスト行 0〜23（y = 0〜383）は透明、行 24（y = 384〜399）は黒で塗りつぶし（グラフィックを隠す）。（→ 01章のテキスト属性：行 0〜23 は属性 0xE1 の空白、行 24 は属性 0x05 の空白）
13. 1 フレーム待ち、明るさ 100% でパレットを表示（一瞬で現れる。フェードはしない）。

### 4.3 トランジション（フィールド画面 → 戦闘画面）

フィールド画面とそのパレットが表示されている状態から始める。明るさ t のパレット表示とは、各色成分 v（0〜15）を、t ≤ 100 なら v × t ÷ 100、100 < t < 200 なら 15 − (15 − v) × (200 − t) ÷ 100、t ≥ 200 なら 15 として表示すること（→ 01章）。

1. 1 フレーム待つ。
2. 明るさ 180 で表示 → 4 フレーム待つ。
3. 明るさ 120 で表示 → 4 フレーム待つ。
4. 明るさ 180 で表示 → 4 フレーム待つ。
5. 明るさ 100 で表示。
6. 次を i = 0〜23 の 24 回繰り返す：1 フレーム待ち、j = 0, 2, 4, …, 14 の 8 通りについて、y = i×16 + j の横線と y = 383 − i×16 − j の横線（いずれも x = 0〜639）を色 14 で描く。上からは偶数行、下からは奇数行が 16 行ずつ埋まり、24 回で y = 0〜383 がすべて色 14 になる。
7. 1 フレーム待ち、明るさ 0（真っ黒）で表示。
8. 画面の横ずらし（§6.8）を 0 に戻し、グラフィック画面全体（640×400）を色 14 で塗りつぶす。
9. 画面全体を背景コピーとして保存（この後 §4.2 手順 4 で背景描画後に再保存される）。

フレーム数：1 + 4 + 4 + 4 + 24 + 1 = 38 フレーム。

### 4.4 敵画像の表示モード

§6.7 参照。

### 4.5 後始末（戦闘終了時、勝利・逃走・敗北（モード0）共通）

1. 1 フレーム待ち、明るさ 0 で表示（真っ黒）。
2. グラフィック画面全体を色 0 で塗りつぶす。
3. テキスト層をフィールド用マスクに戻す（→ 21章）。
4. キーバッファを空にする。

その後、呼出し元が §3.2 の後処理をする。

## 5. 戦闘者データ

### 5.1 味方の初期化（パーティ記録 → 戦闘者）

パーティの i 番目（スロット i）について、そのキャラクタのパーティ記録から:

1. 名前（0x50、20 バイト）、レベル。
2. **武器**（装備欄 0。0xFF ならアイテム 255）のレコードから:
   - 攻撃属性：0x19 のビット 0〜5 → 属性 1〜6 を持つ。
   - 追加効果：0x23 のビット 0 → 毒、ビット 1 → 暗闇、ビット 2 → 沈黙、ビット 3 → 混乱、ビット 4 → 麻痺、ビット 5 → 即死。
   - 命中率 = 0x22、追加効果の発生率 = 0x24。
3. 会心率 = 5（%、固定）。
4. **防具**（装備欄 1〜4：鎧・盾・兜・装飾品。0xFF ならアイテム 255）それぞれの 0x19 のビット 0〜5 が立っている属性について、耐性（添字 14〜19）をコード 1（耐性：ダメージ半減）にする。他の耐性はすべてコード 0。
5. 生存フラグ、状態 0〜5、習得済み魔法 30 個、HP、MP、最大 HP、最大 MP。
6. 4 能力の基準値・現在値 = 装備込み能力値（0x20〜）。
7. その他（防御中・ため・行動・対象・フラグ類）は 0。行動テーブルは空、フラグなし、カウンターなし。

### 5.2 敵の初期化（敵レコード → 戦闘者）

敵スロットに敵番号 n を設定するとき（戦闘開始時および変身時）。画面上の位置（§4.2 手順 8）はそのまま保持し、他はすべて初期化してから:

1. 名前（0x00、17 バイト）。敵である印、生存。
2. 行動テーブル → 行動リスト・フラグ・反撃魔法（§2.1.1）。
3. 命中率 = フラグ（種別11）があれば 70、無ければ 95。会心率 = フラグ（種別10）があれば 30、無ければ 5。
4. 耐性 20 項目（0x28〜0x2C）。
5. HP = 最大 HP = 0x1A、MP = 最大 MP = 0x1E。
6. 4 能力の基準値・現在値 = 0x20〜0x27。
7. 大きさ区分 = 0x46、画像番号 = 0x11、経験値、お金、逃走成功率、ドロップ率、ドロップアイテム、変身 HP 閾値、変身先。
8. 状態はすべて 0、攻撃属性なし、追加効果なし（敵の通常攻撃は無属性）。レベルは 0（使わない）。

### 5.3 書き戻し（戦闘者 → パーティ記録）

勝利・逃走成功・全滅のいずれでも、各味方スロットについて:

1. HP（16 ビット符号付きで格納）、MP、生存フラグを書き戻す。
2. 状態は **毒（0）と麻痺（5）だけ**を書き戻す。暗闇・沈黙・混乱・睡眠（1〜4）は書き戻さないので、パーティ記録のこれらは戦闘前の値のまま残る（通常は 0。イベント等で戦闘前に立っていれば、戦闘中に治っても記録には残り続ける）。
3. 能力の現在値の変化（能力上下）は書き戻さない（戦闘限り）。
4. 最後に、パーティの誰かが毒なら状態ブロックの「毒歩行フラグ」を立て、誰もいなければ下ろす（→ 21章）。

経験値・レベル・お金・アイテムは勝利処理（§15.1）がパーティ記録・所持品へ直接反映する。

### 6.2 ウィンドウ枠とメッセージ行

- ウィンドウ枠は → 23章と共通：(x を 8 単位に切り捨て, y) から 幅（8 単位に切り捨て）× 高さを色 0 で塗り、外側から順に矩形（両端含む）を描く：(x, y)–(x+w−1, y+h−1) 色 14、(x+1, y+1)–(x+w−2, y+h−2) 色 14、(x+2, y+1)–(x+w−3, y+h−2) 色 15、(x+1, y+2)–(x+w−2, y+h−3) 色 15、(x+3, y+3)–(x+w−4, y+h−4) 色 15。
- **メッセージ行 n（0〜2）の表示**：まず行を消去（(104, 16 + 24n) から幅 432 × 高さ 16 を色 0 で塗る）してから、(104, 16 + 24n) に色 15 で文字列を描く。
- 「メッセージ全消去」= 行 0〜2 を消去。
- 「メッセージ表示（単独）」= 全消去してから行 0 に表示。

### 6.3 パーティウィンドウ

- 描画：ウィンドウ枠 (288, 240, 352, 144) を描き、味方スロット 0〜(人数−1) の行を「通常」で描く。
- **パーティ行 i**（y = 256 + 24i）。モードは「通常」と「強調」。敵スロットに対して行描画を要求されたら何もしない。
  1. 背景：通常なら (296, y−2) から幅 336 × 高さ 20 を色 0 で塗る。強調なら同じ範囲を色 15 で塗り、以下の文字色を 0 にする（通常は 15）。
  2. 名前を (312, y) に。
  3. 状態欄を (448, y) に：気絶していれば WORD.DAT の状態名（s = 6）。生存していれば状態 5→0 の順に調べて最初に見つかった状態の名前（麻痺 > 睡眠 > 混乱 > 沈黙 > 暗闇 > 毒 の優先順位）。どれも無ければ `Ｌ%2d`（レベル）。
  4. 数値を (512, y) に：HP を右詰め 4 桁、`/`、最大 HP を右詰め 4 桁、MP を右詰め 5 桁（例 ` 348/ 348   32`）。
  - 文字の種類（v1.1 で追記）：レベル表示の「Ｌ」は全角（SJIS 0x826B）、続くレベルの数字 2 桁（空白埋め右詰め）は半角。数値欄は空白・数字・`/` を含めてすべて半角（1 文字 8 ドット）で、桁あふれ時（5 桁以上の HP など）は詰めずにそのまま右へ延びる。負の値は `-` 付きで同じ書式。
- 「行を更新する」と書いた箇所は、その行を通常モードで描き直すこと。

### 6.4 敵名ウィンドウ

1. ウィンドウ枠 (120, 240, 168, 144) を描く。
2. 敵 0 から順に、生存している敵だけ、r 行目（r = 0 から詰める）に名前を (144, 256 + 24r) に色 15 で描く。r 行目が何番目の敵かを記録し、表示行数を記録する（対象選択で使う）。

敵名ウィンドウは頻繁に描き直される（トップメニュー・コマンドメニュー・対象選択・オート中の各ターン開始時など）。

### 6.5 汎用カーソル選択（→ 23章と共通）

基準位置 (x, y)、項目数 N、初期位置、キャンセル可否のモード（0 = 不可、1 = 可、2 = 可かつ決定時にカーソルを消す）で選択する。

- カーソルは外字 SJIS 0xEB9F を (x + 16, y + 16 + 24 × 位置) に描く。
- 点滅：フレームカウンタを 0 から数え、カウンタ 0〜3 の間は色 15 で描き、21〜23 の間は色 0 で描き（消す）、31 を超えたら 0 に戻す（約 31 フレーム周期）。キー入力でカーソルが動いたらカウンタを 0 に戻し、旧位置のカーソルを色 0 で消す。
- 毎フレーム、キーバッファから 1 キー取り出す：
  - ESC：モード 1/2 なら効果音 3、カーソルを消して「キャンセル」を返す。モード 0 なら無視。
  - リターン/スペース：効果音 2、カーソルを（モード 2 なら色 0、他は色 15 で）描いて現在位置を返す。
  - 上（テンキー8 含む）：効果音 1、位置を 1 減らす（0 未満なら N−1）。
  - 下（テンキー2 含む）：効果音 1、位置を 1 増やす（N−1 を超えたら 0）。
  - 左右（テンキー4/6 含む）：効果音 1 のみ（移動しない）。
- N = 0 なら即座に「キャンセル」を返す。
- 開始時にキーバッファを空にする。

戦闘で使う選択:

| 選択 | 基準位置 | N | モード | カーソル位置 |
|---|---|---|---|---|
| トップメニュー | (0, 240) | 3 | 0（キャンセル不可） | (16, 256 + 24i) |
| コマンドメニュー | (0, 240) | 4 | 1 | (16, 256 + 24i) |
| 敵の対象選択 | (112, 240) | 敵名ウィンドウの表示行数 | 1 | (128, 256 + 24r) |
| 味方の対象選択 | (280, 240) | パーティ人数 | 2 | (296, 256 + 24i) |

初期位置はいずれも 0（前回位置を記憶しない）。

### 6.6 トップメニューとコマンドメニューの描画

- **トップメニュー**：1 フレーム待ち、コマンドウィンドウ枠を描き、(32, 256 + 24i) に WORD.DAT 0x78 / 0x83 / 0x8E（i = 0〜2）を描き、敵名ウィンドウを描いてから選択。
- **コマンドメニュー**：1 フレーム待ち、コマンドウィンドウ枠を描き、(32, 256 + 24i) に WORD.DAT 0x99 / 0xA4 / 0xAF / 0xBA（i = 0〜3）を描き、敵名ウィンドウを描いてから選択。
- **敵の対象選択**：1 フレーム待ち、敵名ウィンドウを描いてから選択。結果は表示行 r に対応する敵（スロット = 敵番号 + 5）。
- **味方の対象選択**：1 フレーム待ち、パーティウィンドウを描いてから選択。結果はスロット番号（気絶している味方も選べる）。
- **実行中ラベル**：コマンドウィンドウを描き直した後、(24, 256) に 1 語だけ描く（§7）。

### 6.7 敵画像の表示モード

敵画像の描画位置は (8 単位に切り捨てた x, y)、大きさは 小 80×96 / 大 160×128。画面外のドットは描かない。

| モード | 内容 |
|---|---|
| 通常 | 各ドットについて、マスクが 1 なら画面のドットを 0 にしてから 4 プレーンの色（B=1, R=2, G=4, I=8 の和）を OR する。マスクが 0 なら画面のドットに色を OR する（通常は色 0 なので背景がそのまま見える） |
| 白 | マスク・B・R・G のいずれかのビットが 1 のドットを色 15 にする（輝度プレーンは見ない）。他のドットは変えない |
| 消去 | 画像の矩形範囲を背景コピーから復元する |
| 踏み込み | 「通常」と同じ描き方で、y を 8 ドット下げて描く |

### 6.8 演出とフレーム数

フレーム数の数え方：演出開始時にフレームカウンタを 0 にし、「カウンタが k 以上になるまで 1 フレームずつ待つ」。

- **ヒット点滅**（敵がダメージ・状態異常を受けたとき）：k = 2, 4, 6, …, 16 の各時点で、奇数回目（1, 3, 5, 7 回目）は「白」、偶数回目は「通常」で描く。計 16 フレーム。最後は通常表示。
- **消滅**（敵が倒れた・逃げた）：k = 4, 8, …, 40 の各時点で、奇数回目は「通常」、偶数回目は「消去」。計 40 フレーム。最後は消えた状態。
- **踏み込み**（敵の行動開始時）：
  1. k = 1 まで待つ。「消去」→「踏み込み」。
  2. k = 6 まで待つ。「消去」→「通常」。
  3. 画像の下端のすぐ下 8 行（(x, y + 高さ) から 幅 × 8）を色 14 で塗る（踏み込みではみ出した部分を消す）。
  計 6 フレーム。
- **画面揺れ**（味方が HP ダメージを受けたとき）：次を 3 回：2 フレーム待ち、表示開始位置を 16 ドットずらす（画面全体が左へ 16 ドットずれ、はみ出した分は反対側から回り込む → 01章）、2 フレーム待ち、ずらしを戻す。計 12 フレーム。
- **魔法発動演出**（→ 23章と共通）：魔法の効果音を鳴らす。フラッシュなしなら待ち 3 単位。フラッシュありなら次を 10 回：16 色すべてをフラッシュ色（各成分 × 17 の 8 ビット値）にして 2 フレーム待ち、表示、元のパレットに戻して 1 フレーム待ち、表示（計 30 フレーム）。

## 7. 戦闘メインループ

以下を勝敗が決まるまで繰り返す（1 周 = 1 ターン）。

1. メッセージ全消去。
2. **オート継続中**なら：1 フレーム待ち、敵名ウィンドウを描き、「待ち 1 単位して、その時点で ESC（キャンセルキー）が押されていればオートを解除して抜ける」を最大 4 回繰り返す（最大 28 フレーム）。
   - 「押されている」は**その瞬間の押下状態**（直前の VSYNC で取り込んだ入力状態の「取消」）で判定する。キーバッファは見ないし、取り出しも空にもしない（この間に押した ESC の打鍵はバッファに残るが、次のトップメニューの選択が開始時にバッファを空にするので影響しない）。したがって待ち 1 単位の途中で ESC を押して離した場合は解除されない。（v1.1 で追記）
3. オートでない（または手順 2 で解除された）場合：
   1. 行動可能な味方（生存し、麻痺・睡眠・混乱のいずれでもない）が 1 人でもいれば、**コマンド入力**（§8）。いなければ全味方の行動を「何もしない」・防御中を解除し、1 フレーム待ち、敵名ウィンドウを描き、待ち 4 単位（トップメニューも出ないので逃走もできない）。
   2. **敵のターン開始処理**（§9.1）。
   3. 1 フレーム待ち、コマンドウィンドウ枠を描き直す（空にする）。コマンド入力でオートが選ばれていれば (24, 256) に WORD.DAT 0x83 を描く。
   
   オート継続中（手順 2 で解除されなかった）なら、敵のターン開始処理だけを行う（コマンドウィンドウは前のターンの表示のまま）。
4. メッセージ全消去。
5. スロット 0 の味方の行動が「逃げる」なら：(24, 256) に WORD.DAT 0x8E を描き、スロット 0 の行動を「何もしない」に変え、**逃走判定**（§14.1）。成功なら後始末（§4.5）して「逃走」を返す。失敗ならこのターンは味方全員何もしないまま続行。
   それ以外でオートでなければ (24, 256) に WORD.DAT 0x78 を描く。
6. **行動順の決定**（§10）。
7. フレームカウンタを 0 にし、6 フレーム待つ。
8. **ラウンド処理**（§11）。結果が:
   - 勝利：書き戻し（§5.3）→ 勝利処理（§15.1）→ 後始末 →「勝利」を返す。
   - 全滅：書き戻し → メッセージ全消去 → 行 0 に WORD.DAT 0x653 → 待ち 5 単位 → キー待ち（戦闘用）。ゲームオーバーモードが 0 以外なら、明るさを 100 から 6 ずつ 2 フレームごとに下げるフェードアウト（→ 01章）をしてタイトル画面へ戻る（戦闘処理には戻らない）。0 なら後始末して「敗北」を返す。
   - 継続：手順 1 へ。

## 8. コマンド入力

### 8.1 トップメニュー

1. オートを解除する。
2. トップメニューを表示して選択（キャンセル不可）。
   - **0（戦う）**：各キャラのコマンド入力（§8.2）へ。
   - **1（オート）**：オートを設定して終了（各キャラの入力は行わない。味方の防御中フラグもここでは変更しないので、前のターンに防御を選んだキャラは防御中のまま。§19 参照）。
   - **2（逃げる）**：スロット 0 の行動を「逃げる」・防御中を解除、スロット 1 以降の行動を「何もしない」・防御中を解除して終了。スロット 0 が気絶していても同じ。

### 8.2 各キャラのコマンド

スロット 0 から順に処理する。「戻る」状態（ESC で前のキャラへ戻る途中）を持つ。「パーティウィンドウ再描画が必要」フラグを持つ（一覧ウィンドウがパーティ・敵名ウィンドウを覆ったときに立つ）。

1. 戻る状態なら：現在がスロット 0 ならトップメニュー（§8.1）からやり直し。そうでなければ 1 つ前のスロットへ。
2. そのキャラの防御中を解除。
3. そのキャラが行動不能（気絶、麻痺、睡眠、混乱のいずれか）なら：
   - 戻る状態なら手順 1 へ（さらに前へ戻る）。
   - そうでなければ行動を「何もしない」にし、パーティ行を更新して次のスロットへ（全員終わったら手順 9）。
   （混乱中のキャラはここで「何もしない」になるが、ラウンド処理で混乱行動に置き換わる。）
4. 戻る状態を解除。再描画が必要ならフラグを下ろし、1 フレーム待ってパーティウィンドウを描き直す。
5. そのキャラのパーティ行を強調表示する。
6. コマンドメニューで選択：
   - **キャンセル**：戻る状態にし、パーティ行を通常に戻して手順 1 へ。
   - **0（攻撃）**：行動 = 攻撃。敵の対象選択。キャンセルなら手順 8。決定なら対象 = 選んだ敵のスロット。
   - **1（魔法）**：再描画フラグを立てる。行動 = 魔法。魔法一覧（→ 23章の魔法一覧ウィンドウを位置 (144, 240) に、そのキャラの習得済み魔法、消費 MP を `[%2d]` で表示）で選択。キャンセルなら手順 8。決定した魔法の種別が 0 なら味方の対象選択、2 なら敵の対象選択（いずれもキャンセルなら手順 8）。種別 1・3・4・5・6 は対象を選ばない。一覧では MP が足りない魔法も選べる（実行時に失敗する）。
   - **2（アイテム）**：再描画フラグを立てる。行動 = アイテム。アイテム一覧（→ 23章の所持品一覧ウィンドウを位置 (144, 240) に）で選択。キャンセルなら手順 8。アイテム種別 6 なら味方の対象選択、種別 8 なら発動魔法の種別が 0 なら味方の、2 なら敵の対象選択。それ以外の種別は対象を選ばない（どの種別のアイテムでも選べる。大事な物・装備品なども選べ、実行時に「何も起こらなかった」になる）。
   - **3（防御）**：行動 = 防御、**防御中フラグを即座に立てる**（そのターンの最初から被ダメージ半減が効く）。
7. パーティ行を通常に戻して次のスロットへ。全員終わったら手順 9。
8. （サブ選択のキャンセル）再描画が必要ならフラグを下ろし、1 フレーム待ってパーティウィンドウを描き直し、**同じキャラ**の手順 5 に戻る。
9. 終了処理：1 フレーム待ち、敵名ウィンドウを描く。再描画が必要なら 1 フレーム待ってパーティウィンドウを描き直す。

## 9. 敵の行動決定

### 9.1 敵のターン開始処理（毎ターン、コマンド入力の後）

敵 0 から順に（敵数まで）:

1. 行動を「攻撃」、防御中を解除。
2. 気絶していれば行動を「死亡中」（§11.2 の復活判定に使う）にする。
3. 生存していて、行動リストが 1 件以上あり、ため残りが 0 なら：**乱数を 1 回引き**、（乱数 % 行動リスト件数）番目の項目の種別が 2（防御）なら、行動 = 防御、防御中フラグを立てる。

### 9.2 行動の決定（各行動の直前に毎回）

ラウンド処理でその敵の番が来たとき（複数回行動ならその各回）、混乱していなければ次を行う。

1. 行動が「防御」ならそのまま（決定済み）。
2. 行動リストの各項目 i（先頭から）について重み w_i を計算（§9.3）。w_i > 0 なら **乱数を 1 回引き** w_i に（乱数 % 2）を足す。累積和を記録。
3. 重みの合計が 0 なら行動 = 何もしない。
4. **乱数を 1 回引き**、r = 乱数 % 合計。累積和が r を初めて超える項目を選ぶ。
5. 行動 = 項目の種別、パラメータ = 項目のパラメータ。
6. 対象:
   - 種別 0（攻撃）・4（2回攻撃）・6（毒攻撃）：味方からランダムに選ぶ（§9.5 の味方抽選）。
   - 種別 1（魔法）で魔法種別 0（味方単体＝敵側）：敵 0〜(敵数−1) について自己評価値（§9.4）を求め、**それまでの最大値より真に大きい**ものを対象にする（初期最大値 0、同値なら先のもの）。全部 0 なら対象は変更しない（直前に記録されていた値のまま。手順 2 の重み計算（§9.3）でも魔法種別 0・2 の項目は「同時に対象を記録」するので、その副作用で書かれた値＝最後に重みを計算した該当項目の結果や、前のターン以前の値が残る）。
   - 種別 1 で魔法種別 2（敵単体＝味方側）：味方 0〜(人数−1) について対敵評価値（§9.4）で同様に選ぶ。
   - それ以外は対象を使わない。

### 9.3 重み

| 項目の種別 | 重み |
|---|---|
| 2 防御 | 1 |
| 1 魔法 | 唱えられない（MP が消費 MP 未満、または精神係数が 0 でなくて沈黙中、または魔法種別 4 以上）なら 1。唱えられるなら魔法種別により：0 → 敵全員の自己評価値の最大値（同時に対象を記録）、1 → 敵全員の自己評価値の合計（敵数が 2 以上かつフラグ A（種別7）が無ければ敵数で割る）、2 → 味方全員の対敵評価値の最大値（同時に対象を記録）、3 → 味方全員の対敵評価値の合計（パーティ人数が 2 以上なら人数で割る） |
| 3 逃走 | HP ≤ 最大 HP ÷ 2 なら 100、そうでなければ 50 |
| 5 ため | ため残りが 0 なら 100、そうでなければ 1 |
| 0 攻撃・4 2回攻撃・6 毒攻撃 | ため残りが 0 なら 100、そうでなければ 3000 |

- 「敵全員」「味方全員」は気絶している者も含めて走査する（評価値が 0 になる）。敵数は戦闘開始時の数（逃げた/倒れた敵も数える）。
- 唱えられない魔法の重みが 0 ではなく 1 であるため、MP 不足の魔法も低確率で選ばれ、実行時に「MP が足りない！」になる。
- 「ため残り」は §11.3 手順 10 で行動直前に 1 減らされた後の値で評価される。

### 9.4 評価関数（乱数を使わない）

**対敵評価値**（敵が味方 p に魔法をかける価値）:

1. p が気絶していれば 0。
2. 効果ビット 0（HP ダメージ）がある、または効果ビット 1（MP ダメージ）があって p の MP が 0 でない → 100。
3. 状態 s = 0〜5 の順に、p がその状態でなく効果ビット 2+s がある → 80。
4. 効果ビット 8（即死）がある → 80。
5. 能力 k = 0〜3 の順に、効果ビット 10+k があり p の能力 k の現在値 > 基準値 ÷ 2 → 100。
6. 効果ビット 0〜19 のどれかがある → 1。
7. どれも無い → 60。

**自己評価値**（敵が敵 e（自分を含む）に魔法をかける価値）:

1. 術者にフラグ A（種別7）があり、e が術者自身でなければ 0。
2. e が気絶していれば、効果ビット 8（蘇生）があれば 200、無ければ 0。
3. 効果ビット 0（回復）があれば：HP < 最大HP ÷ 4 なら 120、HP < 最大HP ÷ 2 なら 80、HP ÷ 3 < 最大HP ÷ 4 なら 40、それ以外 1。（効果ビット 0 があればここで確定）
4. 状態 s = 0〜5 の順に、e がその状態で効果ビット 2+s がある → s × 20 + 80。
5. 能力 k = 0〜3 の順に、効果ビット 10+k があり e の能力 k の現在値 < 基準値 × 2 + 10 → 100。
6. 効果ビット 0〜19 のどれかがある → 1。
7. どれも無い → 60。

### 9.5 ランダム抽選

**味方抽選**：生存している味方（スロット順）のリストを作る（麻痺中も含む）。件数 n。

- n = 0 なら「なし」（−1）。（通常、全滅判定が先に成立するので起きない）
- n < 3 なら **乱数を 1 回引き**、リストの（乱数 % n）番目。
- n ≥ 3 なら **乱数を 1 回引き**、r = 乱数 % (4n + 2)。r < 2 ならリストの r 番目、そうでなければリストの (r − 2) ÷ 4 番目。結果としてリストの先頭 2 人は 5/(4n+2)、他は 4/(4n+2) の確率で狙われる。

**敵抽選**：生存している敵のリスト（敵番号順）、件数 n。n = 0 なら「なし」。そうでなければ **乱数を 1 回引き**、リストの（乱数 % n）番目の敵のスロット。

### 9.6 混乱時の行動決定

混乱中の戦闘者の行動は次のように決める（味方・敵とも）。

**味方の場合**:
1. 習得済み魔法（0xFF 以外、並び順）のリストを作る。
2. 沈黙中でなく、リストが空でなければ **乱数を 1 回引き**、乱数 % 8 > 4（5〜7、確率 3/8）なら行動 = 魔法とし、**乱数を 1 回引き** パラメータ = リストの（乱数 % 件数）番目。それ以外（乱数を引かなかった場合を含む）は行動 = 攻撃。

**敵の場合**:
1. 行動リストが空なら行動 = 何もしない で終了。
2. **乱数を 1 回引き**、行動リストの（乱数 % 件数）番目の項目の種別を行動にする。種別 1 ならパラメータも設定。種別 2（防御）なら防御中フラグを立てる。

**対象の決定**（両者共通）:
- 行動が 攻撃・2回攻撃・毒攻撃 なら：**乱数を 1 回引き**、乱数 % 4 が 0 以外（確率 3/4）なら**自分の側**から抽選、0 なら相手側から抽選（§9.5 の抽選でさらに乱数 1 回）。自分自身が選ばれることもある。
- 行動が魔法なら：
  - （敵が魔法種別 0 を使う）または（味方が魔法種別 2 を使う）場合：**乱数を 1 回引き**、乱数 % 4 が 0 以外なら味方から、0 なら敵から抽選。
  - （敵が魔法種別 2 を使う）または（味方が魔法種別 0 を使う）場合：**乱数を 1 回引き**、乱数 % 4 が 0 以外なら敵から、0 なら味方から抽選。
  - つまり単体魔法は 3/4 の確率で本来と逆の側を狙う。魔法種別 1・3 は対象を決めず、実行時に §12.10 で 3/4 の確率で逆側にかかる。
- 逃走・ため・防御・何もしない は対象なし。

## 10. 行動順

1. 全 10 スロットについて、キー = 素早さの現在値 +（生存していれば 1、気絶なら 0）。キー > 0 なら **乱数を 1 回引き**、キーに（乱数 % キー）を足す。（スロット 0 から 9 の順に。空スロットはキー 0 なので乱数を引かない。気絶者も素早さが正なら乱数を引く。）
2. 並べ替え：初期の並びはスロット 0〜9。位置 i = 0〜8 の順に、それぞれ位置 j = i+1〜9 の順に見て、「位置 i のキー < 位置 j のキー」なら位置 i と位置 j の内容（キーとスロット）を入れ替える。こうしてできた並び（キーの大きい順。同点時の順序はこの入れ替え手順の結果に従う）が行動順。

## 11. ラウンド処理

### 11.1 全体

行動順の 10 スロットを先頭から順に処理した後、毒ダメージ処理（§11.4）を行う。各スロットの処理の前に「全滅判定 → 敵全滅判定」を行い、成立すればその時点でラウンドを終える（全滅を優先）。

### 11.2 気絶している戦闘者の番（復活判定）

その番の戦闘者が気絶しているとき：

- 復活フラグ（種別8）を持ち、行動が「死亡中」（このターン開始時点ですでに気絶していた）なら、復活カウンタを 1 増やし、2 以上になったら：カウンタを 0 に戻し、生存、HP = 最大 HP、画像を通常表示で描き、「名前 + WORD.DAT 0x588」を単独表示、待ち 4 単位。
- いずれにしても何もせず次の番へ。

結果として、復活する敵は「倒された後、2 回目のターン開始時点でも気絶していたターン」の自分の番に復活する。逃走した敵は復活フラグが消される（§12.15）。

### 11.3 生存している戦闘者の番

1. 敵なら踏み込み演出（§6.8）。
2. **麻痺**中なら：「名前 + 状態メッセージ(麻痺, 2)」を単独表示、待ち 4 単位、終わり（麻痺は戦闘中に自然回復しない）。
3. **睡眠**中なら：**乱数を 1 回引き**、乱数 % 7 = 3 なら目覚める（睡眠解除、パーティ行更新、「名前 + 状態メッセージ(睡眠, 3)」を単独表示）。そうでなければ「名前 + 状態メッセージ(睡眠, 2)」を単独表示。いずれも待ち 4 単位で終わり（目覚めたターンも行動しない）。
4. **混乱**中なら：**乱数を 1 回引き**、乱数 % 9 = 3 なら正気に戻る（混乱解除、行更新、「名前 + 状態メッセージ(混乱, 3)」を単独表示、待ち 4 単位で終わり。行動しない）。そうでなければ混乱時の行動決定（§9.6）。
5. **沈黙**中なら：**乱数を 1 回引き**、乱数 % 15 = 3 なら沈黙解除、行更新、「名前 + 状態メッセージ(沈黙, 3)」を単独表示、待ち 4 単位（その後行動する）。
6. **暗闇**中なら：**乱数を 1 回引き**、乱数 % 13 = 3 なら暗闇解除、行更新、「名前 + 状態メッセージ(暗闇, 3)」を単独表示、待ち 4 単位（その後行動する）。
7. 行動回数 n = 3 回行動フラグ（種別13）があれば 3、なければ 2 回行動フラグ（種別12）があれば 2、どちらもなければ 1。
8. 以下を最大 n 回繰り返す（第 1 回、第 2 回…）。
9. 「行動中断」フラグを下ろす。
10. ため残りが 0 でなければ 1 減らす。
11. 味方でオート中なら：混乱中なら混乱時の行動決定（§9.6、手順 4 に続いて 2 回目）、そうでなければオートバトル AI（§13）。
12. 敵なら：第 2 回以降は行動を「攻撃」にリセット（ターン開始時の防御抽選を引き継がない）。混乱中なら混乱時の行動決定（§9.6、手順 4 に続いてもう 1 回）、そうでなければ行動の決定（§9.2）。
13. 行動を実行：

| 行動 | 実行内容 |
|---|---|
| 攻撃 | 通常攻撃（§12.1） |
| 魔法 | 魔法の詠唱（§12.10） |
| 防御 | §12.13 |
| 逃げる（敵） | 敵の逃走（§12.15） |
| 2回攻撃 | 通常攻撃を 1 回。ここで全滅判定が成立すれば即座にラウンドを「全滅」で終える。成立しなければ同じ対象に通常攻撃をもう 1 回（対象がすでに倒れていれば、攻撃者が敵なら何も起きず、味方なら §12.1 の対象差し替え） |
| ため | §12.14 |
| 毒攻撃 | 追加効果「毒」を持たせ追加効果発生率を 100 にして通常攻撃し、その後追加効果「毒」と発生率を 0 に戻す（元の値には戻さず 0 にする。敵はもともと 0 なので影響なし） |
| アイテム | §12.12 |
| 何もしない / 死亡中 | 何もしない |

14. 実行後、現在の戦闘者が睡眠・麻痺・気絶のいずれかなら残りの回数を打ち切る。行動中断フラグが立っていれば下ろして打ち切る（変身直後など、§12.3）。
15. 全滅判定が成立すれば「全滅」、敵全滅判定が成立すれば「勝利」でラウンドを終える。**手順 14 で打ち切った場合もこの判定は必ず行う**（打ち切りは「次の回に進まない」だけで、判定を飛ばして次のスロットへ進むのではない。したがって行動順の最後の戦闘者が敵を全滅させた直後に打ち切りになっても、毒ダメージ（§11.4）より先に勝利が決まる）。（v1.1 で追記）
16. 手順 9 へ（回数が残っていれば）。

### 11.4 毒ダメージ（ラウンドの最後）

全 10 スロットを 0 から順に：生存していて毒状態で HP > 1 の戦闘者について、**乱数を 1 回引き**、d = (最大 HP + 乱数 % 30) ÷ 20（0 なら 1）。d < HP なら HP から d を引き、そうでなければ HP = 1（毒では死なない）。パーティ行を更新（敵は表示なし）。メッセージは出さない。

その後、全滅判定 → 敵全滅判定 の順に判定し、どちらも不成立なら「継続」。

### 11.5 判定

- **全滅判定**：味方全員（スロット 0〜人数−1）が「気絶」または「麻痺」なら成立。
- **敵全滅判定**：
  1. 敵の中に「気絶していて（逃走も含む）リーダーフラグ（種別9）を持つ者」がいれば：生存している敵をすべて 気絶・HP 0 にして、それぞれ（敵番号順に）消滅演出をし、成立。
  2. そうでなければ、生存している敵が 1 体もいなければ成立。

## 12. 行動の実行

本節で「術者/攻撃者」は現在行動中の戦闘者、「対象」は処理中の対象。

### 12.1 通常攻撃

1. 対象が気絶している場合：攻撃者が敵なら**何もせず終わる**（メッセージも出ない）。味方なら敵 0 から順に最初の生存している敵を対象にする。生存している敵がいなければ何もせず終わる。（混乱した味方が気絶中の味方を狙った場合も、生存している敵に差し替わる。）
2. 命中率 = 攻撃者の命中率。攻撃者が暗闇なら命中率 ÷ 4。
3. **乱数を 1 回引き**、乱数 % 100 < 命中率 なら命中:
   1. **乱数を 1 回引き**、乱数 % 100 < 会心率 なら会心。
   2. ダメージ = 会心なら 攻撃力×2 − 対象の防御力÷3、そうでなければ 攻撃力 − 対象の防御力÷2（能力はすべて現在値）。
   3. ため残りが 0 でなければ、ため残りを 0 にし、ダメージに 攻撃力÷2 を足す。
   4. 属性倍率 m = 64 から始め、攻撃者の攻撃属性 1〜6 の順に、持っている属性について対象のその属性の耐性コードが 1 なら m ÷ 2、2 なら m = 0、3 なら m × 2。
   5. m > 64 ならダメージ × 2、m < 64 ならダメージ ÷ 2（倍率は最大でも 1 回だけ適用）。
   6. m = 0 ならダメージ 0。そうでなく、ダメージ < 2 なら **乱数を 1 回引き** ダメージ = 乱数 % 2。そうでなければダメージ = ばらつき（ダメージ, 3）（§12.16）。
   7. ダメージ ≤ 0 ならダメージ 0、会心も取り消す。
   
   外れなら：ため残りを 0 にする（ためは失われる）。ダメージ 0。
4. メッセージ全消去。効果音（攻撃者が敵なら 5、味方なら 4）。行 0 に「攻撃者名 + WORD.DAT 0x4F7」。待ち 3 単位。
5. 会心なら行 1 に WORD.DAT（対象が敵なら 0x5FC、味方なら 0x619）、待ち 4 単位。
6. **ダメージ適用**（§12.2、物理モード）。
7. ダメージ適用後の対象の HP が 0 でなく、ダメージ（防御による半減前の値）が 0 でなく、かつ「対象が防御中でダメージがちょうど 1」でない場合：
   1. 追加効果：状態 0〜6 の順に、攻撃者がその追加効果を持っていれば **乱数を 1 回引き**、乱数 % 100 < 追加効果発生率 なら状態付与（§12.6、倍率 100 → 基本付与率 100%）。
   2. カウンター：物理攻撃カウンター（§12.11、種類 0）を試み、発動しなければ、攻撃者の攻撃属性 1〜6 の順に、持っている属性について属性カウンター（種類 = 属性番号）を試み、最初に発動したところでやめる。

### 12.2 HP ダメージ適用

入力：ダメージ値、モード（物理 / 魔法 / 吸収）、失敗メッセージ種別（魔法のみ）。

1. 対象が防御中ならダメージ ÷ 2。
2. ダメージ > 9999 なら 9999。（負のダメージは下限処理なしでそのまま以降へ進む。§12.16 末尾。v1.1 で追記）
3. ダメージが 0 の場合：
   - 物理モード、または失敗種別 3：効果音 7、行 1 に「対象名 + WORD.DAT 0x514」、待ち 4 単位、「効果あり」とする。終わり。
   - 失敗種別 2：行 1 に「対象名 + WORD.DAT 0x5DF」、待ち 4 単位、「効果あり」とする。終わり。
   - それ以外（魔法で失敗種別 0/1）：何もせず終わる（効果ありにしない）。
4. 物理モード以外なら「効果あり」とする（「効果あり」は魔法の失敗メッセージ判定に使う。§12.9）。
5. メッセージ：
   - 物理・魔法モード：`%sに%dのダメージ！`（対象名、ダメージ）、効果音 6。
   - 吸収モード：ダメージ > 対象の HP ならダメージ = 対象の HP。対象が敵なら `%sのＨＰを%d奪った！`、味方なら `%sはＨＰを%d奪われた！`。術者の HP = min(術者HP + ダメージ, 術者の最大HP)。効果音なし。
6. 行 1 にメッセージ。
7. 演出：対象が敵ならヒット点滅 → 待ち 2 単位。対象が味方で吸収モードなら待ち 4 単位。対象が味方でそれ以外なら画面揺れ → 待ち 2 単位。
8. ダメージ < 対象の HP なら HP から引く。そうでなければ対象を**気絶させる**（HP 0、生存フラグ 0、状態 0〜5 をすべて解除、能力の現在値を基準値に戻す、ため残り 0）。
9. 術者と対象のパーティ行を更新（敵なら何もしない）。
10. 対象の HP が 0 なら：敵なら行 2 に「対象名 + 状態メッセージ(気絶, 1)」→ 消滅演出。味方なら行 2 に「対象名 + 状態メッセージ(気絶, 0)」→ 待ち 2 単位。
    HP が 0 でなく、ダメージが 0 でなく、対象が睡眠中なら：**乱数を 1 回引き**、乱数 % 4 = 1 なら睡眠解除、行更新、行 2 に「対象名 + 状態メッセージ(睡眠, 3)」、待ち 2 単位。（睡眠中でなければ乱数を引かない）
11. **変身判定**（§12.3）。
12. 待ち 2 単位。

### 12.3 変身

HP ダメージ適用の最後に、対象が「生存している敵」で、変身先が 0xFF でなく、HP ≤ 変身 HP 閾値 なら変身する。

1. 変身先の敵レコードの画像番号（0x11）が現在の画像番号と同じなら：そのスロットを変身先の敵番号で初期化し直す（§5.2。位置は保持）。大きさ区分は今の画像のものを使う。画像は描き直さない。
2. 異なるなら：消滅演出 → スロットを初期化し直す → 変身先の EGD を読む（パレットも変身先のものに置き換わる。ファイルが無い/50 バイト未満ならパレットは変わらず画像は空）→ 明るさ 100% でパレットを表示 → 通常表示で描く。
   - このとき戦闘者の大きさ区分は変身先の敵レコード 0x46 の値のまま（§4.2 手順 6 と違い、EGD の 0x30 で置き換えない）。通常表示・白・消去の描画範囲はこの区分で決まり、踏み込み後の下端の塗りつぶし（§6.8）だけは EGD の 0x30 の値で決まる。両者が食い違うデータでの見た目は 参照実装どおり【未確認】。
   - 食い違う場合の画像データの解釈（参照実装の挙動。v1.1 で追記）：EGD の読み込みは常に **EGD 自身の大きさ（0x30）** で行う。すなわち 5 枚のプレーンを、0x32 から順に「EGD の幅/8 × EGD の高さ」バイトずつ切り出す（§2.5）。描画（通常・白・踏み込み）は **戦闘者の大きさ区分** の寸法（小 10 バイト×96 行、大 20 バイト×128 行）で行い、各プレーンの切り出したバイト列を先頭から「戦闘者の区分の 1 行のバイト数」ごとに行として読む。プレーンの長さを超えた位置のバイトは 0（マスク 0・色 0 ＝ 何も描かない）とする。結果として、区分が大で EGD が小なら 960 バイトを 20 バイト幅で読むので上 48 行に横にずれた像が出て残りは透明、区分が小で EGD が大なら各プレーンの先頭 960 バイトだけを 10 バイト幅で読むので像が斜めに崩れる。消去は戦闘者の区分の矩形を背景コピーから復元する。EGD ファイルが無い/50 バイト未満のときは EGD の大きさを「小」、全プレーン空として同じ規則に従う（何も描かれず、踏み込み後の塗りは小の位置・幅）。サンプルゲーム 21 本には、大きさ区分と EGD の 0x30 が食い違う敵レコードは無い（変身先も含む）。（v1.1 で追記）
3. 変身後の戦闘者の「行動中断」フラグを立てる。

初期化し直すので、HP・MP は変身先の最大値、状態・能力変化・ため・防御中・行動はすべてリセットされる。経験値・お金・ドロップも変身先のものになる。行動中断フラグは、変身した敵がその時点で行動中なら残りの回数を打ち切らせ、そうでなければその敵の次の行動開始時に下ろされる（効果なし）。

### 12.4 MP ダメージ

入力：値、モード（通常 / 吸収）。

1. 値 > 対象の MP なら値 = 対象の MP。
2. 値 = 0 なら何もせず終わる（効果ありにしない）。（負の値は手順 1・2 のどちらにも当たらず、そのまま以降へ進む。§12.16 末尾。v1.1 で追記）
3. 値 > 9999 なら 9999。
4. 「効果あり」とする。
5. メッセージ：吸収なら対象が敵で `%sのＭＰを%d奪った！`、味方で `%sはＭＰを%d奪われた！`、術者の MP = min(術者MP + 値, 術者の最大MP)。通常なら `%sのＭＰが%d減った！`。
6. 行 1 に表示。対象が敵ならヒット点滅 → 待ち 2 単位、味方なら待ち 4 単位。
7. 対象の MP が 9999 未満なら値を引く（9999 以上は無限で減らない）。
8. 術者と対象のパーティ行を更新。

防御による半減はない。効果音もない。

### 12.5 HP 回復・MP 回復

**HP 回復**（値 v）：v = 0 なら何もしない。v > 9999 なら 9999。「効果あり」。v = 9999 なら `%sのＨＰが全回復した！`、そうでなければ `%sのＨＰが%d回復した！`（v は上限で切った回復量。実際の増加量ではない）を行 1 に。待ち 4 単位。HP = min(HP + v, 最大HP)。行更新。

**MP 回復**（値 v）：v = 0 なら何もしない。v > 999 なら 999。「効果あり」。v = 999 なら `%sのＭＰが全回復した！`、そうでなければ `%sのＭＰが%d回復した！`。待ち 4 単位。MP = min(MP + v, 最大MP)。行更新。

### 12.6 状態付与

入力：倍率 m（属性倍率。通常攻撃の追加効果では 100）、状態 s（0〜6）。

1. 基本付与率：m > 64 なら 100、m = 64 なら 90、m = 0 なら 0、それ以外（0 < m < 64）なら 60。
2. 対象の耐性（添字 2+s）が 1 なら −30、2 なら 0 に固定、3 なら +20。（m = 0 で付与率 0 でも弱点なら 20 になる）
3. **乱数を 1 回引き**（付与率に関わらず必ず引く）、乱数 % 100 ≥ 付与率 なら失敗で終わり（メッセージなし）。
4. 「効果あり」。
5. メッセージ種類：s < 6 で対象がすでにその状態なら 2、そうでなく対象が敵なら 1、味方なら 0。行 1 に「対象名 + 状態メッセージ(s, 種類)」。
6. s = 6 なら対象を気絶させる（§12.2 手順 8 と同じ）。そうでなければ状態 s を立てる。
7. 対象が味方なら待ち 4 単位 → 行更新。敵ならヒット点滅 →（s = 6 なら消滅演出）→ 待ち 2 単位。

### 12.7 状態回復・蘇生

入力：回復量（蘇生時の HP）、状態 s（0〜6）。

1. s = 6（蘇生）で対象が生存していれば何もしない。s < 6 で対象がその状態でなければ何もしない。
2. 「効果あり」。
3. s = 6：生存、HP = min(回復量, 最大HP)、HP ≤ 0 なら 1、復活カウンタを 0 に。s < 6：状態 s を解除。
4. s = 6 で対象が敵なら行 1 に「対象名 + WORD.DAT 0x588」、画像を通常表示で描く。それ以外は行 1 に「対象名 + 状態メッセージ(s, 3)」。
5. 待ち 4 単位。行更新。

### 12.8 能力の上下

**能力低下**（値 v、能力 k）:
1. 成功率：対象の耐性（添字 10+k）のコードが 0 なら 90、1 なら 60、2 なら 0、3 なら 100。
2. **乱数を 1 回引き**（必ず引く）、乱数 % 100 ≥ 成功率 なら終わり。
3. v > 999 なら 999。現在値から v を引き、基準値 ÷ 2 を下回ったら基準値 ÷ 2 にする。
4. 実際の低下量 d = 元の値 − 新しい値。d > 0 なら「効果あり」、行 1 に `%sの%sが%d下がった！`（対象名、WORD.DAT 0x16 + 11k の能力名、d）、待ち 4 単位。d ≤ 0 なら何も表示しない。

**能力上昇**（値 v、能力 k）：成功判定なし。v > 999 なら 999。現在値に v を足し、基準値 × 2 + 10 を超えたらそこまでにする。上昇量 d > 0 なら「効果あり」、`%sの%sが%d上がった！`、待ち 4 単位。

能力の現在値は行動順（素早さ）、攻撃・防御の計算、魔法の係数計算に使われる。

### 12.9 魔法の数値計算

**魔法ダメージ量**（術者、対象、属性倍率 m）:
1. d = 威力。
2. 攻撃係数 a が 0 でなければ:
   - 効果ビット 20（自爆）があれば d += 術者の現在 HP × a ÷ 4。なければ d += (術者の攻撃力 × a を 16 ビット符号付きに切り詰めた値) ÷ 10。
   - 効果ビット 21（防御無視）が無ければ d −= (対象の防御力 × a を 16 ビット符号付きに切り詰め) ÷ 20。
3. 精神係数 c が 0 でなければ:
   - d += (術者の精神力 × c を 16 ビット符号付きに切り詰め) ÷ 10。
   - 効果ビット 21 が無ければ d −= (対象の精神力 × c を 16 ビット符号付きに切り詰め) ÷ 40。
4. m > 64 なら d × 2、m < 64 なら d ÷ 2。
5. m = 0 なら結果 0（乱数を引かない）。
6. d < 2 なら **乱数を 1 回引き** 結果 = 乱数 % 2。
7. それ以外は 結果 = ばらつき（d, 魔法のばらつき値）。

**回復量**（術者）:
1. d = 威力。攻撃係数 a が 0 でなければ d += (術者の攻撃力 × a を 16 ビット符号付きに切り詰め) ÷ 10。精神係数 c が 0 でなければ d += (術者の精神力 × c を 16 ビット符号付きに切り詰め) ÷ 10。
2. d < 2 なら **乱数を 1 回引き** 結果 = 乱数 % 2。それ以外は ばらつき（d, ばらつき値）。

**失敗メッセージ種別**（MAGIC.DAT 0x22）と挙動:

| 種別 | 対象ごとの失敗（成功率判定に外れた、または効果が何も無かった）時 | HP ダメージが 0 になった時 | 詠唱の最後に「どの対象にも効果が無かった」時 |
|---|---|---|---|
| 0 | 何も出さない | 何も出さない | 行 1 に WORD.DAT 0x5A5（名前なし）、待ち 5 単位 |
| 1 | 何も出さない | 何も出さない | 行 1 に WORD.DAT 0x5C2（名前なし）、待ち 5 単位 |
| 2 | 行 1 に「対象名 + WORD.DAT 0x5DF」、待ち 4 単位 | 同左（効果ありとする） | 出さない |
| 3 | 効果音 7、行 1 に「対象名 + WORD.DAT 0x514」、待ち 4 単位 | 同左（効果ありとする） | 出さない |

（種別 0/1 の参照オフセットは「0x4A0 + (種別 + 9) × 0x1D」。§19 の【未確認】を参照。）

### 12.10 魔法の詠唱

1. 「効果あり」を下ろす。メッセージ全消去。行 0 に「術者名 + 発動メッセージ（MAGIC.DAT 0x29）」。
2. 魔法発動演出（§6.8。効果音・フラッシュ。失敗する場合も行う）。
3. 術者の MP < 消費 MP なら：待ち 1 単位、行 1 に「WORD.DAT 0x0B + `が足りない！`」、待ち 5 単位で終わり（MP は減らない。カウンターも起きない）。
4. 精神係数が 0 でなく術者が沈黙中なら：待ち 1 単位、行 1 に「`しかし` + 術者名 + 状態メッセージ(沈黙, 2)」、待ち 5 単位で終わり。（精神係数 0 の魔法＝技は沈黙中でも使える）
5. 術者の MP が 9999 未満なら消費 MP を引く。術者のパーティ行を更新。
6. 「混乱による逆転」判定（以下、魔法種別 1・3 のときだけ行う）：術者が混乱中なら **乱数を 1 回引き**、乱数 % 4 が 0 以外（確率 3/4）なら逆転。混乱していなければ乱数を引かず逆転しない。
7. 対象への適用（術者が味方の場合）:
   - 種別 0：指定された対象に補助型（§12.10.2）。
   - 種別 1：逆転しなければ味方全員（スロット 0〜人数−1、**気絶者も含む**）に順に補助型。逆転なら生存している敵全員に。
   - 種別 2：指定された対象に攻撃型（§12.10.1）。
   - 種別 3：逆転しなければ生存している敵全員（敵番号順）に攻撃型。逆転なら生存している味方全員に。
   
   術者が敵の場合:
   - 種別 0：指定された対象に補助型。
   - 種別 1：逆転しなければ敵全員（敵 0〜敵数−1、**気絶者・逃走者も含む**）に補助型。逆転なら味方全員（気絶者含む）に。
   - 種別 2：指定された対象に攻撃型。
   - 種別 3：逆転しなければ生存している味方全員に攻撃型。逆転なら生存している敵全員に。
   
   「生存している〜全員」は、その対象の番が来た時点で生存しているかどうかで判定する（前の対象への処理で倒れた者は除かれる）。
   種別 4〜6 は何もしない。
8. 「効果あり」が下りていて種別が 0〜3 なら：効果ビット 0〜19 が 1 つも無い魔法なら「効果あり」として待ち 2 単位。
9. 「効果あり」が下りていて失敗種別が 0 または 1 なら、全体失敗メッセージ（§12.9 の表）を表示して待ち 5 単位。（種別 4〜6 の魔法を戦闘で使うと、MP を消費してここに来る）
10. 効果ビット 20（自爆）があれば術者を気絶させ（§12.2 手順 8）、味方ならパーティ行更新、敵なら消滅演出。
11. 魔法カウンター（§12.11）。

#### 12.10.1 攻撃型（1 対象への適用）

1. 対象が気絶していれば：術者が敵なら何もせず終わる。味方なら敵 0 から順に最初の生存している敵に差し替える（いなければ終わり）。
2. メッセージ行 1・2 を消去。
3. **乱数を 1 回引き**、乱数 % 100 ≥ 成功率 なら失敗。術者が暗闇なら続けて **乱数を 1 回引き**、乱数 % 10 < 攻撃係数 なら失敗（暗闇でなければ引かない）。失敗なら対象ごとの失敗処理（§12.9）をして終わり。
   - 暗闇の 2 回目は**成功率判定の結果に関係なく**引く（成功率判定ですでに失敗と決まっていても、術者が暗闇なら必ず 2 回目を引く。短絡しない）。攻撃係数が 0 の魔法でも、術者が暗闇なら 2 回目を引く（結果は必ず「失敗にしない」）。暗闇かどうかは術者（行動中の戦闘者）の状態で見る。対象が複数の魔法（種別 3）では対象ごとにこの 1〜2 回を引く。（v1.1 で修正）
4. 属性倍率 m = 64 から始め、効果ビット 14〜19 の順に、立っている属性について対象のその属性の耐性（添字 14〜19）で m を変える（1 → ÷2、2 → 0、3 → ×2）。
5. 「HP/MP 耐性補正」：値に対象の耐性（添字 0）を適用する（1 → ÷2、2 → 0、3 → ×2）。
6. 効果ビット 0（HP ダメージ）があれば：d = HP/MP 耐性補正（魔法ダメージ量（m））。効果ビット 21（防御無視）があり対象が防御中なら d × 2（ダメージ適用での半減を打ち消す）。HP ダメージ適用（§12.2。効果ビット 9 があれば吸収モード、無ければ魔法モード、失敗種別を渡す）。その結果対象が気絶していれば：失敗種別が 2 以上なら「効果あり」を下ろし、この対象の処理を終える（以降の効果は適用しない）。
7. 効果ビット 1（MP ダメージ）があれば：d = HP/MP 耐性補正（魔法ダメージ量（m））（改めて計算し乱数も改めて引く）。MP ダメージ（§12.4。効果ビット 9 があれば吸収）。
8. 状態 s = 0〜6 の順に、効果ビット 2+s があれば状態付与（§12.6、倍率 m）。
9. 能力 k = 0〜3 の順に、効果ビット 10+k があれば 能力低下（魔法ダメージ量（m）を先に計算してから、§12.8）。
10. 「効果あり」が下りていれば対象ごとの失敗処理。
11. 失敗種別が 2 以上なら「効果あり」を下ろす。

#### 12.10.2 補助型（1 対象への適用）

1. メッセージ行 1・2 を消去。
2. **乱数を 1 回引き**、乱数 % 100 ≥ 成功率 なら対象ごとの失敗処理をして終わり（対象が気絶していても判定する）。
3. 対象が生存していれば：
   - 効果ビット 0 があれば HP 回復（回復量）。
   - 状態 s = 0〜5 の順に、効果ビット 2+s があれば状態回復（回復量を**先に計算してから**、s）。対象がその状態でなくても回復量の計算（乱数）は行われる。
   - 能力 k = 0〜3 の順に、効果ビット 10+k があれば 能力上昇（回復量、k）。
4. 効果ビット 8 があれば蘇生（回復量を計算してから。対象が生存していれば計算だけして何もしない）。
5. 「効果あり」が下りていれば対象ごとの失敗処理。失敗種別が 2 以上なら「効果あり」を下ろす。

補助型には MP 回復の効果は無い（効果ビット 1 は無視）。

### 12.11 カウンター（反撃魔法）

カウンター種類 k：0 = 物理攻撃、1〜6 = 属性 1〜6。

**発動条件**（すべて満たすとき）：攻撃者（現在行動中の者）が味方、対象が敵、対象がカウンター k を持つ（種別 14+k）、対象が生存、麻痺・睡眠していない、対象の MP ≥ 反撃魔法の消費 MP、反撃魔法の精神係数が 0 でなければ対象が沈黙していない。

**発動**：反撃魔法の対象は、魔法種別 0 なら反撃する敵自身、種別 2 なら攻撃者、それ以外は（使わない）。反撃する敵を術者として魔法の詠唱（§12.10）を丸ごと行う（MP 消費・発動メッセージ・演出・混乱による逆転を含む。術者が敵なので魔法カウンターは連鎖しない）。終わったら元の行動者・対象に戻す。

**魔法カウンター**（味方が魔法を使った後。アイテムによる魔法も同じ）：術者が敵なら何もしない。
- 魔法種別 2：最後に処理した対象について、効果ビット 14〜19 の順に立っている属性 e で属性カウンター e を試み、最初に発動したところでやめる。
- 魔法種別 3：敵 0〜敵数−1 のすべて（気絶者も走査するが発動条件で弾かれる）について、それぞれ同様に属性順に試みる。
- 魔法の成否・効果の有無に関係なく試みる。魔法種別 0・1 では起きない。物理攻撃カウンター（k = 0）は魔法では起きない。

### 12.12 アイテム使用

1. アイテム種別が 6〜8 なら所持品を減らす：所持品の先頭 256 枠を順に見て、空き枠（個数 0）に当たったら**何もせずアイテム使用全体を終える**（同じターンに他のキャラが最後の 1 個を使い切った場合など。メッセージも出ない）。そのアイテムの枠が見つかれば、消耗フラグ（0x17）が 0 でなければ 1 個減らし、0 になったら所持品を詰める。種別 0〜5・9・10 は減らさない。
2. 「効果あり」を下ろす。メッセージ全消去。行 0 に `%sは%sを使った！`（使用者名、アイテム名）。
3. 種別 8 なら発動魔法の魔法発動演出（§6.8）、そうでなければ待ち 3 単位。
4. 種別 8（魔法効果）：発動魔法の種別により、0 → 指定対象に補助型、1 → 味方全員（気絶者含む）に補助型、2 → 指定対象に攻撃型、3 → 生存している敵全員に攻撃型（§12.10.1/2）。MP 消費・沈黙判定・混乱による逆転は無い。種別 4〜6 は何もしない。
5. 種別 6（単体回復）：指定対象に回復アイテム効果。種別 7（全体回復）：味方全員（気絶者含む）に順に回復アイテム効果。
6. 種別 8 の場合：「効果あり」が下りていて発動魔法の失敗種別が 0 または 1 なら、行 1 に `しかし何も起こらなかった！`、待ち 5 単位。効果ビット 20（自爆）があれば使用者を気絶させてパーティ行更新。魔法カウンター（§12.11）。
   種別 8 以外：「効果あり」が下りていれば行 1 に `しかし何も起こらなかった！`、待ち 5 単位（種別 0〜5・9・10 は常にこれになる）。

**回復アイテム効果**（1 対象）:
1. 対象が生存していれば：
   - 状態回復ビットの 0x40（蘇生）が立っておらず HP 回復量が 0 でなければ、HP 回復（HP 回復量を**符号なし 16 ビット**として。負の値は大きな正の値になり 9999 に切られて全回復になる）。
   - MP 回復量が 0 でなければ MP 回復（同じく符号なし 16 ビット）。
   - 状態 0〜5 の順に、回復ビットが立っていれば状態回復（回復量 0, s）。
2. 0x40 が立っていれば蘇生（回復量 0 → HP は 1 で生き返る）。

（フィールドで使った場合は HP 回復量で蘇生するが、戦闘では HP 1 で蘇生する。→ 23章との違い）

### 12.13 防御

メッセージ全消去、行 0 に「名前 + WORD.DAT 0x531」、待ち 5 単位、防御中フラグを立てる。

防御中フラグの効果：HP ダメージ適用で ÷2（§12.2）。味方はコマンド入力時に、敵はターン開始処理の防御抽選時に立つので、その戦闘者の番より前の攻撃から効く。解除は次のコマンド入力（味方）/ 次のターン開始処理（敵）。

### 12.14 ため（敵のみ）

メッセージ全消去、行 0 に「名前 + WORD.DAT 0x54E」、待ち 5 単位、ため残り = 2。

ため残りは各行動の直前に 1 減る（§11.3 手順 10）。次の行動時には 1 になっており、そのとき通常攻撃（2回攻撃・毒攻撃含む）が命中すれば攻撃力 ÷ 2 が加算されて 0 になる。外れた場合も 0 になる。攻撃以外をすれば、さらに次の行動前に 0 になる。ため残りが 0 でない間、敵の重みは攻撃系 3000・ため 1 になり、ターン開始時の防御抽選もしない。

### 12.15 敵の逃走

メッセージ全消去、行 0 に「名前 + WORD.DAT 0x56B」、消滅演出、待ち 4 単位。その敵の経験値・お金・ドロップ率を 0、気絶状態（生存フラグ 0、HP 0）、復活フラグを下ろす。リーダーフラグは残るので、リーダーが逃げると敵全滅判定（§11.5）により残りの敵も消え、勝利になる。

### 12.16 ばらつき関数

入力：値 v、ばらつき p。

1. p ≤ 0 なら v をそのまま返す（乱数を引かない）。
2. **乱数を 1 回引き**、v に（乱数 % 3）を足す。
3. t = v × p ÷ 12。
4. t > 1 なら **乱数を 1 回引き**、v に (t ÷ 2 − 乱数 % t) を足す。
5. v を返す。

通常攻撃は p = 3（t = v ÷ 4 で、おおむね ±12.5%）。フィールドの魔法効果（→ 23章）も同じ関数。

**結果が負になる場合**（v1.1 で追記）：手順 4 の加算の最小は v + t ÷ 2 − (t − 1) なので、p が 25 以上だと（v が十分大きければ）結果が負になり得る（例：p = 25、手順 2 の後の v = 48 → t = 100、最小 48 + 50 − 99 = −1）。p ≤ 24 では負にならない。サンプルゲーム 21 本の MAGIC.DAT にばらつき値 25 以上の魔法は無い。乱数の剰余は 0〜t−1 の非負値、除算は 0 方向への切り捨て。結果は**下限処理をせずそのまま**呼出し元へ返し、呼出し元も負の値を特別扱いしない（参照実装の挙動。原本の挙動は【未確認】だが、原本も符号付き整数の演算で、負の値を弾く処理は確認されていない）。戦闘での帰結：

- 通常攻撃：§12.1 手順 3.7 で 0 に切り上げられるので影響なし。
- HP ダメージ適用（§12.2）：防御中なら ÷2（0 方向へ切り捨て）。0 でないので「効果あり」になり、`%sに%dのダメージ！` に負の数（例 `-5`）をそのまま表示し、効果音 6・ヒット点滅/画面揺れも通常どおり。手順 8 は「ダメージ < HP」が常に成り立つので HP − ダメージ ＝ **HP が増える**（最大 HP を超えてもそのまま。上限処理なし）。手順 10 の睡眠覚醒判定は「ダメージが 0 でない」ので行う（乱数 1 回）。吸収モードでは「ダメージ > 対象の HP」が成り立たないので切り詰めず、`奪った！` にも負の数を表示し、術者の HP は min(術者HP + ダメージ, 最大HP) で**減る**（下限処理なし。0 以下になっても気絶にはならず生存のまま）。
- MP ダメージ（§12.4）：手順 1 の切り詰めも手順 2 の 0 判定も効かず、「効果あり」、`%sのＭＰが%d減った！` に負の数、対象の MP が 9999 未満なら MP − 値 ＝ **MP が増える**（上限処理なし）。吸収なら術者の MP が減る（下限処理なし）。
- 回復（§12.5）：v が負なら「効果あり」、`%sのＨＰが%d回復した！` に負の数を表示し、HP = min(HP + v, 最大HP) で**減る**（下限処理なし。0 以下でも気絶にならない）。MP も同様。
- 能力低下（§12.8）：v が負なら現在値が**増える**（上限処理なし）。低下量 d ≤ 0 なのでメッセージは出ず「効果あり」にもならない。能力上昇で v が負なら現在値が減る（下限は無い。d ≤ 0 なのでメッセージなし）。
- 蘇生（§12.7）：HP = min(回復量, 最大HP) が 0 以下なら 1。

## 13. オートバトル AI（味方）

オート中、混乱していない味方は各行動の直前に次で行動を決める。評価の途中で「処理中の対象」を書き換えるが、実行時に改めて設定されるので影響しない。

### 13.1 手順

1. 習得済み魔法を先頭から順に見て、**最初の空き（0xFF）で打ち切る**（それ以降に習得済み魔法があっても評価しない）。各魔法について魔法価値（§13.3）を求める（30 件まで）。
2. 攻撃価値 = 最良攻撃（§13.2。対象も記録）。
3. 魔法 0〜29 の価値（評価しなかったものは 0）、最後に攻撃価値の計 31 個を順に見て、「それまでの最大値以上」なら最大値と選択を更新する（初期最大値 0。同値なら**後のもの**が選ばれ、攻撃は魔法と同値なら攻撃が選ばれる）。
4. 最大値 ≤ 0 なら行動 = 何もしない。選択が攻撃なら行動 = 攻撃。魔法なら行動 = 魔法、パラメータ = その魔法。
5. 対象を決め直す：攻撃なら最良攻撃をもう一度行う（対象を記録）。魔法で種別 0 なら、味方 0〜人数−1 について味方価値（§13.4）を**改めて計算**し（乱数も改めて引く）、それまでの最大値より真に大きいものを対象に（初期 0）。種別 2 なら敵 0〜敵数−1 について敵価値で同様。

### 13.2 攻撃価値・最良攻撃

**攻撃価値**（敵 e への通常攻撃の価値、乱数なし）:
1. e が気絶していれば 0。
2. d = 自分の攻撃力 − e の防御力 ÷ 2。
3. 属性倍率 m を §12.1 手順 3-4 と同様に求め、m > 64 なら d × 2、m < 64 なら d ÷ 2（m = 0 でも ÷ 2 のみで 0 にはしない）。
4. e の HP < d なら d に d ÷ 5 を足す（倒せる相手を優先）。

**最良攻撃**：敵 0〜敵数−1 について攻撃価値を求め、それまでの最大値（初期 0）より真に大きいものを対象として記録し、最大値を返す（全部 0 以下なら対象は変更されず 0 を返す）。

### 13.3 魔法価値

1. 唱えられない（MP 不足、精神係数 ≠ 0 かつ沈黙、種別 4 以上）なら 0。
2. 種別 0：味方 0〜人数−1 の味方価値の最大値（真に大きいときだけ更新して対象を記録）。
3. 種別 1：味方全員の味方価値の合計。人数が 2 以上なら人数で割る（味方はフラグ A を持たないので常に割る）。
4. 種別 2：敵 0〜敵数−1 の敵価値の最大値（対象を記録）。
5. 種別 3：敵全員の敵価値の合計。敵数（戦闘開始時の数）が 2 以上なら敵数で割る。

### 13.4 敵価値・味方価値

**敵価値**（敵 e に攻撃魔法をかける価値）:
1. e が気絶している、または効果ビット 0（HP ダメージ）が無ければ 0。
2. 属性倍率 m を §12.10.1 手順 4 と同様に求める。
3. d = 魔法ダメージ量（m）（§12.9。**乱数を引く**。HP/MP 耐性補正・成功率は考慮しない）。
4. e の HP < d なら d に d ÷ 5 を足す。
5. 効果ビット 20（自爆）があれば d ÷ 2。

**味方価値**（味方 p に補助魔法をかける価値）:
1. p が気絶していれば：効果ビット 8（蘇生）があれば (p の最大 HP を 16 ビット符号付きとして) × 10、無ければ 0。
2. v = 0。
3. 効果ビット 0 があれば：h = 回復量（§12.9。**乱数を引く**）、増加量 = min(HP + h, 最大HP) − HP。HP < 最大HP ÷ 4 なら v = 増加量 × 10、HP < 最大HP ÷ 2 なら v = 増加量 × 5、それ以外 v = 0。
4. 状態 s = 0〜5 の順に、p がその状態で効果ビット 2+s があれば v に (s + 1) × (最大HP（16 ビット符号付き）÷ 4) を足す。
5. 効果ビット 20 があれば v ÷ 2。

能力上昇・状態付与・MP ダメージだけの魔法は価値 0 なので、オートでは使われない。

## 14. 逃走

### 14.1 味方の逃走判定

1. 成功率 = 100 から始め、生存している敵それぞれの逃走成功率（0x2E）のうち最小のものにする（より小さければ置き換え）。
2. テストプレイ中で SHIFT が押されていれば成功率 = 100。
3. **乱数を 1 回引き**、乱数 % 100 < 成功率 なら成功：行 0 に WORD.DAT 0x4BD、書き戻し（§5.3）、キー待ち（戦闘用）。後始末して「逃走」を返す。
4. 失敗：行 0 に WORD.DAT 0x4DA、待ち 5 単位。そのターンは味方全員が何もしない。

- 生存している敵の 1 体でも逃走成功率 0 なら決して逃げられない（ボス戦の「逃げられない」はこれで表現される）。
- 状態ブロックの「脱出禁止」フラグ（フィールドの脱出魔法用、→ 23章）は戦闘の逃走には関係しない。
- 逃走の判定はラウンドの前（行動順の決定より前）に行われる。逃走を選べるのはトップメニューからだけなので、行動可能な味方が 1 人もいないターンは逃走できない。

### 14.2 敵の逃走

行動テーブルの種別 3。§12.15 参照。

## 15. 戦闘終了

### 15.1 勝利処理

書き戻し（§5.3）の後に行う。

1. メッセージ全消去、行 0 に WORD.DAT 0x636。
2. 合計経験値・合計お金 = 敵 0〜敵数−1 **全員**（倒した敵、リーダー全滅で消えた敵を含む。逃げた敵は 0 になっている）の経験値・お金の和。
3. ドロップ：敵 0 から順に、まだドロップが決まっていなければ **乱数を 1 回引き**、乱数 % 100 < ドロップ率 ならドロップ = その敵のドロップアイテム（0xFF なら「決まらない」まま次の敵へ）。決まったら以降の敵では乱数を引かない（ドロップは最大 1 個）。
4. 経験値・お金・ドロップのいずれかがあれば：キー待ち（戦闘用）→ メッセージ全消去。表示行番号を 0 にする。
5. 経験値 > 0 なら：待ち 2 単位 → 表示行に `それぞれ%dの経験値を獲得！`（行番号 +1）→ パーティ全員（**気絶者を含む**）について、経験値 = min(経験値 + 合計, 9999999)、レベルアップ判定（§16）を行いレベルが上がったか記録 → 待ち 2 単位。
6. お金 > 0 なら：待ち 2 単位 → 表示行に `お金を%d%s手に入れた！`（行番号 +1）→ 所持金に加算（上限 999999）→ 待ち 2 単位。
7. ドロップがあれば：待ち 2 単位 → 表示行に「アイテム名 + `を手に入れた！`」→ 所持品に 1 個追加（同じアイテムの枠があり 99 個なら追加されない。空き枠が無ければ追加されない。メッセージは変わらない）→ 待ち 2 単位。
8. パーティの並び順に、レベルが上がったメンバーごとに：キー待ち（戦闘用）→ メッセージ全消去 → 行 0 に `%sはレベル%dになった！`（名前、新しいレベル）。何レベル上がっても 1 人 1 回。
9. キー待ち（戦闘用）。

### 15.2 敗北

§7 手順 8 参照。全滅判定は「全員が気絶または麻痺」なので、麻痺だけで全滅しても敗北になる（書き戻しで麻痺状態のまま記録される）。

### 15.3 逃走成功

§14.1 参照。経験値等は得られない。

## 16. レベルアップ（勝利時に使う計算。→ 23章のステータス表示と共通）

### 16.1 必要経験値

レベル L に達するのに必要な累計経験値 E(L):

1. L < 2 なら 0。L > 99 なら L = 99 として計算。
2. a = L + 2。
3. t = ((a × a + 23) × (a × (a − 4))) ÷ 111 + 1。
4. f = (パラメータB − 10) × a + (パラメータA + 5) × 100。
5. E(L) = t × f ÷ 100 + パラメータC。

（パラメータ A, B, C はパーティ記録 0x68, 0x69, 0x6A の符号なしバイト。中間値は **64 ビット**符号付きで計算する（t × f は L = 99・A = B = 255 で約 4.6×10¹⁰ になり 32 ビットを超える）。23章 §1.2 と同じ式。全 21 本の D2 サンプルの PLAYER.DAT 252 レコードで「次のレベルの必要経験値」欄と一致することを確認済み。原本の演算幅は【未確認】）

経験値との比較（§16.2 の「経験値 ≥ E(レベル + 1)」）は、E を 64 ビット符号なしとみなして行う。B < 10 などで E が負になると非常に大きな値として扱われ、そのレベルへは上がらない（23章 §1.2）。

### 16.2 レベルアップ判定

1. 「レベル ≠ 最大レベル かつ 経験値 ≥ E(レベル + 1)」である間：レベルを 1 上げ、習得レベル（0x83〜）がその新レベルに等しい各項目 i について魔法を習得する（§18 のビルド差分）。
2. 能力値を再計算（§16.3）。
3. 1 回でもレベルが上がったら「上がった」。

HP・MP の現在値はレベルアップでは増えない（最大値だけが変わる）。

### 16.3 能力値の再計算

1. レベルが最大レベル以上なら最大レベルにする。
2. 各値（最大HP・最大MP・4 能力）について、K = 成長の折れ点レベル（0x66）、B = レベル1 の値、G = 成長量として:
   - K < L なら 値 = B + (G × (K − 1) を 16 ビット符号付きに切り詰め) ÷ 10 + G × (L − K) ÷ 20
   - そうでなければ 値 = B + G × (L − 1) ÷ 10
   - 上限：最大HP 9999、最大MP 999、能力 999 を超えたら上限に。その後 16 ビット符号付きとして格納。
3. 次のレベルの必要経験値 = レベルが最大レベルなら 0、そうでなければ E(レベル + 1)。
4. 装備込み能力値 = 素の能力値 + 装備（0xFF 以外）の能力補正の合計を 0〜999 に制限。
5. 習得済み魔法の各項目 i について、習得可能魔法リストの項目 i と異なっていれば空き（0xFF）にする。

## 17. 乱数を引く箇所の一覧（順序）

1 ターンの中で乱数を引く順序は次のとおり（条件を満たさない箇所では引かない）。

1. **コマンド入力中**：引かない（カーソル選択は乱数を使わない）。
2. **敵のターン開始処理**（§9.1）：敵 0 から順に、生存・行動リストあり・ため残り 0 の敵ごとに 1 回。
3. **味方の逃走判定**（§14.1）：逃走を選んだターンのみ 1 回。成功時はその後のキー待ちで不定回数。
4. **行動順**（§10）：スロット 0〜9 の順に、キー > 0 のスロットごとに 1 回。
5. **ラウンド**（§11）：行動順に各戦闘者について
   1. 睡眠中：1 回（% 7）。
   2. 混乱中：1 回（% 9）、続けて混乱時の行動決定（§9.6）。
   3. 沈黙中：1 回（% 15）。暗闇中：1 回（% 13）。
   4. 各行動回ごとに：（オート中の味方/敵で混乱中なら再度 §9.6）、行動決定（敵：§9.2 の重みごとの % 2 → 選択の % 合計 → 対象抽選。味方オート：§13 の評価で魔法ダメージ量・回復量の計算ごと → 対象の再計算）。
   5. 行動の実行（§12 の各「乱数を 1 回引き」の箇所を記述順に）。
6. **毒ダメージ**（§11.4）：スロット 0〜9 の順に、該当者ごとに 1 回。
7. **勝利時ドロップ**（§15.1）：ドロップが決まるまで敵ごとに 1 回。
8. **キー待ち（戦闘用）**：SHIFT を押していない場合、キー待ちのポーリング 1 回（約 2 ミリ秒ごと）につき 1 回空引きする。プレイヤーの操作タイミングで乱数の状態が変わる（→ 01章）。

主な関数ごとの消費（再掲）：

| 処理 | 引く回数 |
|---|---|
| 通常攻撃 | 命中 1、命中時 会心 1、ダメージ（倍率 0 なら 0、ダメージ < 2 なら 1、それ以外ばらつき 1〜2）、ダメージ適用での睡眠覚醒 0〜1、追加効果ごとに 発生 1 +（発生時）付与 1、カウンター内の詠唱分 |
| ばらつき | p ≤ 0 なら 0、t ≤ 1 なら 1、t > 1 なら 2 |

| 攻撃型（1 対象） | 成功 1、術者が暗闇なら成功判定の結果に関係なく +1（v1.1 で修正）、HP ダメージ量、ダメージ適用の睡眠覚醒、MP ダメージ量、状態付与ごとに 1、能力低下ごとに ダメージ量 + 1 |

## 18. ビルド差分

戦闘処理本体（本章 §4〜§15）には、RPG.EXE のビルド（→ 20章のビルド判別：1996-06 版、1996-08 版、1997-03 版、1997-10 版）による違いは確認されていない。

戦闘から呼ばれるレベルアップ時の魔法習得（§16.2 手順 1）のみ違いがある:

- **1996 年の 2 ビルド（1996-06・1996-08）**：習得レベルが一致した項目 i について、習得済み魔法の項目 i に習得可能魔法リストの項目 i をそのまま書く。
- **それ以外（1997-03・1997-10）**：習得可能魔法リストの項目 i の魔法番号 m について、習得可能魔法リストを先頭から探して最初に m が現れる位置 j の習得済み魔法の項目 j に m を書く。

習得可能魔法リストに同じ魔法番号が重複していない限り、結果は同じ。

## 19. 未確認事項・注意

1. **魔法の全体失敗メッセージのオフセット**：WORD.DAT の位置は「0x4A0 + (失敗種別 + 9) × 0x1D」で求める（種別 0 → 0x5A5、種別 1 → 0x5C2）。フィールドで魔法を使うとき（→ 23章）も同じ式を使う。サンプルの文言とも矛盾しない。
2. **整数の幅**：参照実装は HP・ダメージ・経験値の中間計算を 64 ビットで行う。敵の最大 HP（u32）、経験値・お金（u32）は大きな値を取り得る。原本の 16/32 ビット演算での桁あふれ挙動は【未確認】。本仕様で「16 ビット符号付きに切り詰め」と明記した箇所（魔法の係数×能力値の積、成長量×(K−1)、味方価値の最大 HP）だけは、原本の 16 ビット演算を再現している。味方の HP は書き戻し時に 16 ビット符号付きに切り詰められる。
3. **戦闘パレット**：背景 EBD のパレットは、敵画像を 1 枚でも読めば最後に読んだ EGD のパレットで上書きされる（入りきらずに削除された敵の EGD であっても）。異なる敵の画像はパレットを共有している前提のデータになっている（サンプルの ENS000/ENL000 はほぼ同じパレット）。参照実装の挙動として記述した。
4. **防御中フラグの持ち越し**：トップメニューで「オート」を選んだ場合、各キャラのコマンド入力を通らないため、前のターンに「防御」を選んだキャラの防御中フラグが下ろされず、オート中ずっと被ダメージ半減が続く（オート AI は防御を選ばないので、新たに立つことはない）。参照実装の挙動として記述。
5. **混乱時の二重抽選**：混乱した敵と、オート中の混乱した味方は、ラウンド処理の手順 4 と手順 11/12 で混乱時の行動決定を 2 回行う（乱数も 2 回分引き、2 回目の結果が使われる。敵が複数回行動するなら回ごとにさらに 1 回）。
6. **毒攻撃後の追加効果消去**：行動「毒攻撃」の後、その戦闘者の追加効果「毒」と追加効果発生率は 0 にされる（元に戻さない）。敵しか使わないので実害はない。
7. **対象「なし」**：味方抽選・敵抽選が「なし」を返した場合（全員倒れているなど）の挙動は 参照実装では未定義（判定順序上通常は起きない）。クリーン実装では「何もしない」とするのが安全。
8. **回復アイテムの蘇生 HP**：戦闘中の蘇生アイテムは HP 1 で蘇生させる（フィールドでは HP 回復量で蘇生）。また HP/MP 回復量は符号なし 16 ビットとして扱われ、負の値は全回復になる。参照実装の挙動として記述。
9. **キー待ちと乱数**：キー待ち中に乱数を空引きするため、同じ乱数種でも人間の操作タイミングで結果が変わる。ヘッドレス実行器での比較テストでは、キー入力のフレームを完全に一致させる必要がある。
10. **アイテムの所持品走査**：所持品は 260 枠あるが、戦闘での消費処理は先頭 256 枠だけを見る。
11. **経験値の合算**：リーダー撃破で消えた敵の経験値・お金も勝利時に加算される。逃げた敵は 0。
12. **魔法カウンターの対象**：単体攻撃魔法の後の魔法カウンターは「最後に処理した対象」について判定される。混乱で味方に向いた場合は発動しない。
13. **敵画像の白表示**：白モードは輝度プレーンを見ないため、輝度プレーンだけに色ビットがあるドット（マスク・B・R・G がすべて 0）は白くならない。
14. **変身の行動中断**：変身した敵が行動中でない場合、立てた行動中断フラグはその敵の次の行動開始時に下ろされるので効果がない。
15. **レベル上限を超えたレベル**：パーティ記録のレベルが最大レベルより大きい場合のレベルアップ判定ループの挙動は未検討（データ上通常起きない）。
16. 戦闘開始時に乱数は引かない（エンカウントするグループの決定はフィールド側 → 21章）。
17. **パーティの並びに 12 以上のメンバー番号がある場合**（データ破損。v1.1 で追記）：参照実装は範囲外のパーティ記録を参照するため未定義（原本も範囲外のメモリを読む）。サンプルでは起きない。クリーン実装の推奨は「そのスロットを空として扱い、人数には数える」：空スロットは戦闘者として初期化せず気絶扱い（全滅判定では気絶に数え、対象にも行動順にも入らない）、パーティ行は描かず、書き戻し・経験値加算・レベルアップの対象にもしない。なおフィールド側の一部（アイテム使用者、敗北許可戦闘の敗北後処理）は「12 以上なら主人公 0」と読み替える（→ 23 章 §9.1、22 章）が、戦闘でこれを真似ると主人公 0 が 2 スロットを占め書き戻しが重複するので推奨しない。

## 20. 受け入れテスト観点

1. **敵配置**：小 1〜5 体、大 1〜3 体、混在のグループで、§4.2 の配置式どおりの位置・削除（合計幅 > 624 で末尾削除）になる。例：Ring のグループ 1（小 1 体）は (280,136)、グループ 3（大 1 体「ゾク」）は (240,104)。
2. **画面レイアウト**：Ring でグループ 1 を起動し、メッセージウィンドウ (80,0) 480×96、コマンド・敵名・パーティウィンドウが §6.1 の位置に出る。パーティ行の書式 `マサル  Ｌ 5  348/ 348   32` 相当、選択中キャラの行が白地黒文字。
3. **トランジション**：38 フレームで白っぽい点滅（明るさ 180/120/180）→ 上下からの色 14 の縞埋め → 黒 → 戦闘画面が一瞬で表示。
4. **WORD.DAT の差替え**：Fantasia（「［戦闘態勢］」「必殺の一撃！」「グラン」）、Ring（「で、出た！？」）などで戦闘開始・会心・お金単位の文言が WORD.DAT どおりに出る。
5. **通常攻撃のダメージ**：固定シードで、攻撃力・防御力・ばらつきの式（§12.1、§12.16）から計算した値と表示ダメージが一致する。防御中の対象には半分。ダメージ 0 で「〜は攻撃をかわした！」と効果音 7。
6. **会心**：味方の会心率 5%、フラグ種別10 の敵は 30%。会心時は「攻撃力×2 − 防御力÷3」。
7. **属性**：属性武器（Soul の火龍堰月刀等）で弱点の敵に 2 倍、耐性に 1/2、無効に 0。防具の属性耐性で味方の被ダメージ半減。
8. **状態異常**：睡眠は自分の番に 1/7 で起き、ダメージを受けると 1/4 で起きる。混乱 1/9、沈黙 1/15、暗闇 1/13 で回復。麻痺は治らない。毒はラウンド末に (最大HP + 0〜29) ÷ 20 のダメージで HP 1 未満にならない。戦闘後に毒・麻痺だけが残る。
9. **暗闇**：通常攻撃の命中率が 1/4 になり、攻撃係数のある攻撃魔法が（乱数 % 10 < 攻撃係数）で失敗する。
10. **沈黙**：精神係数 0 でない魔法だけが「しかし〜の魔法は封じられている！」で失敗し MP は減らない。
11. **MP 不足**：「ＭＰが足りない！」（WORD.DAT 0x0B）で MP は減らず、演出（効果音・フラッシュ）は行われる。
12. **MP 9999 の敵**（Ring の敵 3「ディング」）：魔法を使っても MP が減らず、MP ダメージも減らない。
13. **変身**：Ring の敵 1「ディング」（変身閾値 150、変身先 2）で HP ≤ 150 になると敵 2 に変身し、画像番号が違うので消滅→新画像表示、HP 全快。
14. **リーダー**：リーダーフラグの敵を倒す（または逃げられる）と残りの敵が消滅して勝利、全員の経験値が入る。
15. **復活フラグ**：倒された敵が 2 ターン後の自分の番に全快で復活し「〜が生き返った！」。
16. **複数回行動**：フラグ種別12/13 の敵が 2/3 回行動し、眠る・麻痺する・倒れる・変身すると残りが打ち切られる。
17. **カウンター**：物理カウンター・属性カウンターを持つ敵（Jewel・Soul・Disaster など種別 14〜20 を使うゲーム）に攻撃/属性魔法を当てると反撃魔法が詠唱される。ダメージ 0 の攻撃では反撃しない。
18. **逃走**：逃走成功率 0 の敵が生存していると必ず失敗。テストプレイ中 SHIFT で必ず成功。失敗時、そのターン味方は行動しない。
19. **オートバトル**：毎ターン約 28 フレームの間 ESC を押すと次のターンでトップメニューに戻る。オート中は「自動戦闘」ラベル。AI は §13 の価値で魔法/攻撃を選び、瀕死の味方には回復魔法を使う。
20. **勝利**：経験値・お金・ドロップのメッセージ順とキー待ちの位置が §15.1 どおり。複数人のレベルアップは 1 人ずつキー待ち。経験値上限 9999999、所持金上限 999999。
21. **敗北**：ゲームオーバーモード 1 ではフェードアウトしてタイトルへ、モード 0（イベントの敗北許可戦闘）では呼出し元へ戻る。
22. **乱数再現性**：同じ乱数種・同じキー入力フレーム列で、参照実装のヘッドレス実行器（`--battle` 指定）と行動順・ダメージ・ドロップが一致する。
23. **SHIFT**：SHIFT を押し続けると各待ちが 7→3 フレーム/単位になり、勝利時などのキー待ちが 9 フレームで自動的に進む。
