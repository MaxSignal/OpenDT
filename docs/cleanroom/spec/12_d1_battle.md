# 12. D1 戦闘

## この章の範囲

RPGツクール Dante98（D1）の戦闘シーン全体を扱う。

- 戦闘の起動（ランダムエンカウント／イベント戦闘）と、出現する敵の生成
- 戦闘画面のレイアウト（座標・色）、画面切替の演出、BGM
- コマンド入力（戦う／魔法／アイテム／逃げる／自動戦闘）、カーソルの動き、キャンセル規則
- 行動順の決め方、パーティの自動行動（AI）、敵の行動選択（行動ビット・特性フラグ）
- 通常攻撃のダメージ式、会心・痛恨、回避、身構え
- 魔法 32 種の戦闘での効果、アイテム使用
- 状態異常（毒・麻痺・封印・混乱・眠り）の付与・回復・ターン経過
- 敵の「隠れる」「逃げる」「自爆」「突撃」「MP を奪う」「じっとしている」、復活
- 勝利（経験値・お金・レベルアップ）、全滅、逃走、戦闘の後始末
- 演出（敵の点滅・消滅、画面揺れ、パレットフラッシュ）と待ち時間
- 出すメッセージとその順序、乱数を引く順序と回数

## 1. 用語と戦闘中の状態

### 1.1 戦闘者番号

戦闘では 9 人の「戦闘者」を番号 0〜8 で扱う。

| 番号 | 意味 |
|---|---|
| 0〜3 | パーティの並び順スロット 0〜3（そのスロットのキャラクター）。スロットが空（キャラ番号 8 以上、通常は 0xFF）のこともある |
| 4〜8 | 敵スロット 0〜4（番号−4 が敵スロット番号） |

「陣営値」は 0 がパーティ側、4 が敵側を表す。対象の指定に陣営値（0 または 4）がそのまま入ることがあり、これは「その陣営全体」を意味する。

### 1.2 生存判定

- パーティ戦闘者 s が「生存」: スロットが有効（キャラ番号が 8 未満）かつ HP > 0。
- 敵戦闘者 a が「生存」: 最大HP > 0 かつ HP > 0。
- 敵の「最大HP = 0」は「戦場から消えた（逃げた・消えた）」敵を表す。「最大HP ≠ 0 かつ HP = 0」は倒された敵。

**空スロットが「現在の対象」になった場合**（v1.1 で追記）: パーティ側の空スロット（キャラ番号 8 以上）が対象になる経路がある（例: パーティ枠 0 が空のとき、§9.2 注意の「魔法0番・対象0」で行動する場合）。参照実装では次のように扱われる。
- 名前は空文字（「は気絶している‥‥」のように名前なしで出力される）。生存していない扱い。状態は 0 として読まれる。
- HP の増減（§12.5）: HP は何も変わらず、d の正負によらず「倒れた（倒れている）」を返す。したがって攻撃魔法のダメージ表示は「{空}は{量} p.のダメージ！#」→ 画面揺れ → 撃破表示「{空}は気絶してしまった‥‥」となる（HP 0 のメンバーを叩いた場合と同じ見た目）。
- 状態ビットの設定・解除は捨てられる（何も記録されない）。魔法 8〜12 の結果値は §13.4 の表どおり（魔法 11 は状態 0 を反転した扱いで 9＝「混乱してしまった」）。魔法 7 は状態 0 なので失敗。
- 能力変化（魔法 14〜19）は何も変えないが、結果値・表示は表どおり。
- 蘇生（魔法 6）は失敗（結果 0）。HP 0 のメンバーと違って生き返らない。
- 即死（魔法 13）は乱数を 1 回引き、成功すれば何も変えずに撃破表示。
- MP の増減は行わない（減らす・増やすいずれも失敗扱い）。
- 通常攻撃のダメージ計算（§12.2）で対象が空スロットの場合は、防御力・運を読む箇所が 参照実装でも範囲外参照になる。ただし §9.1 手順 2 で生存していない対象は選び直され、敵のランダム対象選択も生存者だけを選ぶので、通常の経路では起きない。

クリーン実装は「名前は空文字、HP 0、状態 0、書き込みは捨てる、蘇生は失敗、MP は変わらない」として実装すればよい。

### 1.3 状態ビット

パーティキャラクターの状態バイト、敵の状態バイトは共通のビット割当て。

| ビット値 | 状態 | 戦闘での主な効果 |
|---|---|---|
| 0x01 | 毒 | ラウンド終了時に HP 減少（HP 1 未満にはならない）。戦闘後も残る |
| 0x02 | 麻痺 | 行動不可。全滅判定では「戦えない」扱い。戦闘後も残る |
| 0x04 | 封印 | 魔法を唱えると MP を消費したうえで失敗。戦闘終了時に解除 |
| 0x08 | 混乱 | 攻撃対象の陣営が反転。パーティはコマンド入力不可で AI 行動。手番ごとに回復判定。戦闘終了時に解除 |
| 0x10 | 眠り | 行動不可。手番ごとに目覚め判定。戦闘終了時に解除 |

ステータス表示の状態文字列は、該当するものを毒→封→乱→眠→ﾏﾋ→（HP 0 なら死亡マーク）の順に調べ、**最後に該当したもの1つだけ**を表示する（→11 章と共通）。

### 1.4 戦闘用能力値（パーティ）

戦闘開始時に、パーティの有効スロットの各キャラクターについて次を計算し、戦闘中はこの値を使う（L = レベル、各素質値は PLAYER.DAT 由来の力・すばやさ・体力・知力・運）。

| 名称 | 式 |
|---|---|
| 最大HP（記録値） | L×体力 + 30 |
| 最大MP（記録値） | L×知力 |
| 戦闘攻撃力 | L×力 + 10 + 装備武器の性能値（武器なしは 0） |
| 戦闘防御力 | L×体力 + 10 + 鎧・盾・兜の性能値の合計（装備なしの部位は 0） |
| 戦闘すばやさ | L×すばやさ + 装備指輪の性能値（指輪なしは 0） |
| 戦闘運 | L×運 |
| （戦闘力・戦闘体力・戦闘知力） | L×力+10、L×体力+10、L×知力。計算はされるが戦闘では使われない |

- 装備は 武器・鎧・盾・兜・指輪 の 5 枠、値 0x80 以上は「なし」。性能値は ITEM.DAT の「性能値（強さ）」フィールド。
- HP・MP の現在値は戦闘開始時に最大値へ切り詰めない。
- 「最大HP（記録値）」はステータス表示、HP 割合の判定、毒ダメージ、蘇生量に使う。HP 回復時の上限は、その時点で L×体力+30 を計算し直した値（戦闘中にレベルは変わらないので結果は同じ）。
- 攻撃力・防御力・すばやさは補助魔法で戦闘中に増減し、0〜9999 に収める。戦闘が終わると捨てられ、次の戦闘開始時に計算し直す。

### 1.5 敵スロットの内容

敵スロット（最大 5）は戦闘開始時に ENEMY.DAT のレコードから写す。

| 項目 | 出典 |
|---|---|
| 名前（17 バイト、NUL 終端） | 名前 |
| 状態 | 0 で開始 |
| 画像番号 | 画像番号（使うときは 48 の剰余） |
| HP・最大HP | どちらも HP |
| 経験値・お金 | 経験値・お金 |
| 攻撃力・防御力・すばやさ | 攻撃力・防御力・すばやさ（戦闘中に補助魔法で 0〜9999 の範囲で変動） |
| 魔法耐性マスク（4 バイト） | 魔法有効マスク |
| 行動ビット（5 バイト）と特性フラグ（1 バイト） | 戦術 6 バイト（レコード先頭から +34〜+38 が行動ビット、+39 が特性フラグ） |

ビット番号の数え方（魔法有効マスク・行動ビットに共通）: 番号 n は「n÷8 番目のバイトの、最上位ビットから n mod 8 番目のビット」（マスク値 0x80 を n mod 8 だけ右シフトしたもの）。

### 1.6 戦闘ごとの作業状態

- 敵スロットごとの「表示列」（16 ピクセル単位の X 位置）
- 戦闘者番号ごとの「隠れ中」フラグ（実際に使うのは敵のみ）、「身構え中」フラグ（実際に立つのは敵のみ）、「このラウンドで行動可能」フラグ
- 「現在の行動」と「現在の対象」（全戦闘者で共有される1組。後述の処理で次々に上書きされる）
- パーティスロットごとの「入力済みコマンド」と「入力済み対象」（戦闘開始時は全スロットとも コマンド=魔法0番・対象=0）
- 行動順（9 要素の戦闘者番号列）

### 1.7 行動コード

「現在の行動」には次の値が入る。

| 値 | 意味 |
|---|---|
| −1 | 通常攻撃 |
| −2 | 逃げる（パーティ） |
| −3 | 自動戦闘（パーティ、入力値としてのみ現れる） |
| 0〜31 | 魔法番号 |
| 32〜159 | アイテム使用（値−32 がアイテム番号） |
| 0x33 | 身構える（敵） |
| 0x34 | 身を隠す（敵） |
| 0x35 | 逃げ出す（敵） |
| 0x36 | 突撃（敵） |
| 0x37 | 自爆（敵） |
| 0x38 | MP を奪う（敵） |
| 0x39 | じっとしている（敵） |

### 1.8 魔法番号と分類

魔法の効果は**番号で固定**されている（MAGIC.DAT が与えるのは名前・消費MP・威力だけ）。

| 番号 | 分類 | 対象種別 | 全体型 |
|---|---|---|---|
| 0, 1, 2 | HP 回復（単体） | 味方1人 | |
| 3, 4 | HP 回復（全体） | 自陣営全体 | ○ |
| 5 | 消える（フィールドではテレポート） | 自陣営全体 | |
| 6 | 蘇生 | 味方1人 | |
| 7 | 毒・麻痺の治療 | 味方1人 | |
| 8 | 毒にする | 敵1体 | |
| 9 | 麻痺させる | 敵1体 | |
| 10 | 魔法封じ | 敵1体 | |
| 11 | 混乱（反転） | 敵1体 | |
| 12 | 眠らせる | 敵1体 | |
| 13 | 即死 | 敵1体 | |
| 14, 15, 16 | 攻撃力・防御力・すばやさを上げる | 味方1人 | |
| 17, 18, 19 | 攻撃力・防御力・すばやさを下げる | 敵1体 | |
| 20, 21, 22 | 攻撃（単体） | 敵1体 | |
| 23, 24, 25 | 攻撃（全体） | 敵全体 | ○ |
| 26, 27, 28 | 攻撃（単体） | 敵1体 | |
| 29, 30, 31 | 攻撃（全体） | 敵全体 | ○ |

対象種別の内部値（コマンド入力と対象確認で使う）: 自陣営全体 = 0、味方1人 = 1、敵1体 = 2、敵全体 = 4。番号 0〜31 の順に並べると
`1,1,1,0,0,0,1,1,2,2,2,2,2,2,1,1,1,2,2,2,2,2,2,4,4,4,2,2,2,4,4,4`。

「全体型」とは番号 3, 4, 23, 24, 25, 29, 30, 31 の 8 種（魔法耐性マスクの扱いと全体処理で特別扱いされる）。番号 5 は対象種別 0 だが全体型ではない。

## 2. 戦闘の起動

戦闘処理は「敵グループ番号」と「イベント戦闘フラグ」を受け取り、結果（1 = 勝利、0 = 全滅、−1 = 逃走）を返す。

### 2.1 ランダムエンカウント（→11 章）

フィールドで徒歩移動が1歩完了したとき、エンカウント歩数カウンタが 0 になり、かつ現在の画面の ENEMYMAP.DAT の値が 0x20 未満なら、その値を敵グループ番号として戦闘に入る。このとき戦闘処理の前に次の「エンカウント演出」を行う。

1. BGM 切替要求: 戦闘 BGM（PLAYER.DAT の戦闘 BGM 番号）。切替は現 BGM のフェードアウト（20 ms × 16 段、約 320 ms）の後に開始（→02, 11 章）。
2. 次を 3 回繰り返す: フィールドパレットを現在のパレットモードで明るさ +6 にして（各成分 +6、15 で頭打ち）待つ（50 ms ≈ 2.8 フレーム）、明るさ補正 0 に戻して待つ（50 ms）。
3. 画面ワイプ: r = 0〜191 について、ライン r とライン 383−r（幅 640）を色 14 で塗る。r を 9 で割った余りが 8 のときだけ VSYNC を1回待つ（合計 21 回）。
4. 戦闘処理を「イベント戦闘フラグ = 偽」で呼ぶ。
5. 戻ったらゲームオーバー判定（→11 章）。

### 2.2 イベント戦闘（→11 章、イベントコマンド「戦闘」）

1. メッセージウィンドウが開いていれば閉じる。
2. そのイベント実行中にまだ BGM 変更コマンド（番号 100 未満の BGM 指定）が実行されていなければ、戦闘 BGM へ切替要求。すでに実行されていれば BGM は変えない（そのイベントで設定した BGM のまま戦う）。
3. エンカウント演出（パレット点滅・ワイプ）は**行わない**。
4. 戦闘処理を「イベント戦闘フラグ = 真」で呼ぶ。グループ番号はコマンドの引数バイト。
5. 戻ったらゲームオーバー判定（ゲームオーバーならイベントを打ち切る）。結果が逃走（−1）ならそのイベントの残りを飛ばして終了する。勝利なら（および「全滅」で終わったがゲームオーバー判定に掛からなかった場合も、§17.2）マップ上のオブジェクトを再描画して続行。

ランダムとイベントの違いは、(a) エンカウント演出の有無、(b) 敵の「1体間引き」（§3 手順 6）の有無、(c) BGM 切替の条件、(d) 逃走後の扱い（イベントは残りを飛ばす）だけである。逃走はイベント戦闘でも可能で、成功判定もない。

## 3. 戦闘の初期化

1. テキスト層の 16 ピクセル黒枠（フィールド表示用）を無効にする。
2. グラフィック画面全体を色 14 で塗りつぶす。
3. 乱数生成器を「フレームカウンタの下位 16 ビット」で種付けし直す（→01 章。フレームカウンタは VSYNC ごとに増え、選択メニューの入力待ちに入るたびに 1 に戻される）。
4. 16 色すべてを PALET2.DAT の色に設定する（以後戦闘中の基準パレット）。
5. グループ番号を 32 で割った余りにする。ENEMY.DAT のレコード「グループ番号×5 + i」（i = 0〜4）のうち HP > 0 のものの数を n とする。
   - n = 0 の場合: 結果 = 勝利。BGM をフィールド BGM に戻す要求をし、後始末（§17.4）をして戻る。画面にはなにも出ない（手順 2・4 の塗りつぶし／パレット変更は後始末で上書きされる）。
6. n < 2 の場合はイベント戦闘フラグを真とみなす。間引き番号を決める: イベント戦闘なら「なし」、そうでなければ **乱数を1回引き、8 で割った余り**（0〜7）。
7. i = 0〜4 の順に、HP = 0 のレコードと、i が間引き番号に等しいレコードを飛ばし、残りを敵スロット 0 から詰めて格納する（§1.5）。格納数を k とする。
   - 間引き番号が 5〜7 のとき、また間引き対象のレコードがもともと空のときは、だれも減らない。したがってランダムエンカウントで敵が 2 体以上いるグループでは、各レコードが 1/8 の確率で消える。
8. 敵スロット i（0 ≤ i < k）の表示列 = i×8 + (5−k)×4 + 1（16 ピクセル単位）。画面上の左端 X = 表示列×16。
   - 例: k=5 → X = 16, 144, 272, 400, 528。k=4 → X = 80, 208, 336, 464。k=3 → X = 144, 272, 400。k=2 → X = 208, 336。k=1 → X = 272。（どの k でも中央寄せになる。既存実装で dm のグループ 1（3 体）を表示し、144/272/400 に並ぶことを確認済み。）
9. パーティの各スロット（キャラ番号 8 以上は飛ばす）について、状態を「毒・麻痺だけ残す」（状態 AND 0x03）にし、§1.4 の値を計算する。
10. 画面切替（スライドイン）:
    1. 表示開始ライン（縦スクロール量）を 250 にする（→01 章: 表示上の y 行には VRAM の (y + 250) 行、はみ出した分は 384 行で折り返し）。
    2. メッセージウィンドウ枠を文字座標 (16,0)〜(63,4) に描く（§4）。メッセージ領域を消去し、「敵と遭遇した！」を出力（制御文字なし、待ちなし）。
    3. s = 250 から始め、s を (s+10) mod 400 と更新しながら s = 10 になる手前まで繰り返す: VSYNC を1回待ち、表示開始ラインを s（ただし s ≥ 384 なら 0）にする。s は 250, 260, …, 390, 0 の 16 通りで、VSYNC 16 回。見た目は、メッセージウィンドウが画面中ほどから上端へ滑り上がる。
    4. 表示開始ラインを 0 にする。
11. 敵表示域 (0,90)〜(639,237) を色 0 で塗る。メッセージウィンドウ枠を描き直し、メッセージ領域を消去する（「敵と遭遇した！」は消える）。
12. 最大HP ≠ 0 の敵スロットを順に描く（§4.3）。
13. ラウンドの繰り返し（§5）へ。

## 5. ラウンドの流れ

戦闘は次のラウンドを決着まで繰り返す。

1. コマンド入力（§6）。
2. ステータスウィンドウを完全再描画（強調表示が消える）。左側のコマンドウィンドウ・敵名ウィンドウは最後に描かれた状態のまま残る（第1ラウンドでだれも入力できなかった場合は、そこは背景色 14 のまま）。
3. 行動順を決める（§7）。
4. 行動順の 1 番目から 9 番目まで、各戦闘者の手番を処理する（§8）。手番の途中で決着（逃走・全滅・勝利）したら戦闘を終える。
5. ラウンド終了処理（§16）。
6. 1 へ戻る。

## 6. コマンド入力

### 6.1 対象メンバーと順序

スロット 0 から 3 へ順に入力する。次のいずれかに当たるスロットは飛ばす: 空スロット、HP = 0、状態に麻痺・混乱・眠りのいずれか（状態 AND 0x1A ≠ 0）。飛ばされたスロットの「入力済みコマンド／対象」は前ラウンドの値（戦闘開始時は 魔法0番／対象0）のまま残る。

入力した（入力画面を出した）スロットには「入力済み印」を付ける（戦闘の間ではなく、このラウンドの入力の間だけ有効）。

### 6.2 1人分の入力画面

次を「入力が確定するまで」繰り返す（下位の選択でキャンセルされたらここからやり直す）。

1. ステータスウィンドウを完全再描画し、このメンバーの行を強調（§4.4）。
2. 敵名ウィンドウ（20,10)〜(41,15) を描き、HP ≠ 0 の敵（隠れ中も含む）の名前を敵スロット順に、桁 23・行 11 から 1 行ずつ表示する。
3. コマンドウィンドウ (0,10)〜(19,15) を描き、選択メニュー（→11 章）を出す: 項目「戦う　　」「魔法　　」「アイテム」「逃げる　」「自動戦闘」、1 列 5 行、項目幅 8 桁、カーソル桁 2・先頭行 11（項目文字は桁 4 から）、初期カーソルは常に先頭「戦う」。
   - 選択メニューの共通仕様（→11 章）: 上下でカーソル移動（上下端で循環）、決定キーで確定（効果音 15）、キャンセルキーで取消（効果音 12）、移動時は効果音 11。押しっぱなしの連続移動はなく、キーを離すまで次の入力を受け付けない。カーソル矢印はフレームカウンタに同期して点滅する。

4. 選んだコマンドで分岐:

**キャンセル**: 「前のメンバーへ戻る」。このスロットより前で入力済み印のある最も近いスロットへ戻ってそのスロットから入力し直す。そのようなスロットがなければ（スロット 0 で取消した場合や、前のスロットがすべて飛ばし対象の場合）、もう一度先頭から順に（飛ばし規則を適用して）入力する。結果として同じメンバーが再度入力することもある。戻ったメンバーの以前の入力内容は、入力し直すことで上書きされる。

**戦う**: 入力済みコマンド = 通常攻撃。敵選択（§6.3）を行い、キャンセルなら手順 1 へ。確定なら選んだ敵の戦闘者番号を入力済み対象とし、このメンバーの入力を終える。

**魔法**: 魔法選択（§6.4）。キャンセルなら手順 1 へ。確定したら入力済みコマンド = 魔法番号。続いて魔法の対象種別（§1.8）で:
- 種別 1（味方1人）: メンバー選択（§6.6）。
- 種別 2（敵1体）: 敵名ウィンドウを描き直してから敵選択（§6.3）。
- 種別 0（自陣営全体）: 対象 = 0（選択なし）。
- 種別 4（敵全体）: 対象 = 4（選択なし）。

選択がキャンセルされたら手順 1 へ。そうでなければ入力済み対象に入れて入力終了。

**アイテム**: アイテム選択（§6.5）。キャンセルなら手順 1 へ。確定したら入力済みコマンド = アイテム番号 + 32。アイテムの種類で:
- 種類 0〜6（その他・装備品・鍵）: 対象は選ばず入力終了（入力済み対象は前の値のまま）。
- 種類 7〜10（HP 回復・MP 回復・毒消し・麻痺治し）: メンバー選択。キャンセルなら手順 1 へ。
- 種類 11（魔法アイテム）: 性能値の下位 5 ビットを魔法番号とみなし、「魔法」と同じ対象種別の規則で対象を決める。

**逃げる**: 全スロットの入力済みコマンドを「逃げる」にして、**コマンド入力全体を終える**（後のメンバーには聞かない。前のメンバーの入力も上書きされる）。

**自動戦闘**: 全スロットの入力済みコマンドを「自動戦闘」にして、コマンド入力全体を終える。自動戦闘はこのラウンドだけ有効で、次のラウンドでは再びコマンドを聞く。

### 6.3 敵選択

1. 敵名ウィンドウを描き直す。
2. HP ≠ 0 の敵（隠れ中を含む）の名前（先頭 16 バイトまで、NUL まで）を敵スロット順に並べる。1 体もいなければキャンセル扱い。
3. 選択メニュー: 1 列・行数 = 敵の数、項目幅 16、カーソル桁 21・先頭行 11（名前は桁 23 から）、初期カーソル先頭。
4. 確定した項目に対応する敵の戦闘者番号を返す。

### 6.4 魔法選択

1. このメンバーが習得済み（習得レベル ≤ 現在レベル）の魔法を番号順に並べた一覧（最大 32、残りは空き）を作る。
2. 1 つもなければ: ステータスウィンドウの位置 (42,10)〜(79,15) に枠を描き、桁 52・行 12 に「魔法は使えません」を表示。キーがすべて離されるのを待ち、続いて決定・キャンセル・方向キーのいずれかが押されるまで待つ。キャンセル扱いで戻る。この待ちは 11 章 §1.3 の「キー押し待ち」ではなく、高速キーを見ない（高速キーでは抜けない）（v1.1 で追記）。
3. 一覧ウィンドウ (24,10)〜(79,15) を描く。表示開始位置 = 0、カーソル = 0（毎回初期化、記憶しない）。
4. 桁 27・行 10（ウィンドウ上枠の位置）に「← Page %d →」（値は 表示開始位置÷4 + 1）を表示。
5. 一覧の (表示開始位置 + j) mod 32 番目（j = 0〜7）を、2 列 × 4 行（列優先: 左列が j=0〜3、右列が j=4〜7）で表示。各項目は「魔法名の先頭 16 バイト」+「 %2dp.」（消費MP）。空きは全角空白 11 文字。項目幅 22、列の間隔 28 桁、カーソル桁 25（左列）・53（右列）、先頭行 11（文字は桁 27・55 から）。
6. 選択メニュー（ページ送りあり）:
   - 右列で右キー: 表示開始位置を +4（mod 32）し、カーソルは右列の同じ行に置いて手順 4 から。すなわち一覧が 1 列分（4 項目）左へずれる。
   - 左列で左キー: 表示開始位置を −4（mod 32）し、カーソルは左列の同じ行。
   - 列内の左右キーは列移動、上下キーは列内循環。
   - キャンセル: キャンセル扱いで戻る。
   - 確定: その項目が空き、または未習得なら、カーソル位置をそこにしたまま選択メニューを出し直す。そうでなければその魔法番号を返す。
   - **消費MP は選択時には確かめない**（不足は唱えたときに判明する）。

### 6.5 アイテム選択

1. 一覧ウィンドウ (24,10)〜(79,15) を描く。所持品 50 枠に対して、表示開始位置 = (アイテムカーソル記憶値 ÷ 10)×10、カーソル = 記憶値 mod 10（記憶値はフィールドのアイテム画面と共有 →11 章）。
2. 桁 27・行 10 に「← Page %-2d→」（値は 表示開始位置÷5 + 1）。
3. 所持品の (表示開始位置 + j) mod 50 番目（j = 0〜9）を 2 列 × 5 行で表示。項目は「アイテム名の先頭 16 バイト」+「 ×%2d」（個数）、空き枠（値 0x80）は全角空白 11 文字。項目幅 22、カーソル桁 25・53、先頭行 11。
4. 選択メニュー（ページ送りあり）: 右列で右キー → 表示開始位置 +5（mod 50）、カーソルは右列同じ行。左列で左キー → −5、左列同じ行。キャンセルでキャンセル扱い。確定した枠が空きならカーソルをそこにして出し直す。空きでなければ、アイテムカーソル記憶値 = その枠の番号（0〜49）とし、アイテム番号を返す。

### 6.6 メンバー選択

1. ステータスウィンドウ位置に枠を描き直し、各スロットの名前・HP/MP・状態を §4.2 手順 2 と同じ位置に描く（見出しビットマップは描かない）。
2. メンバー選択（→11 章）: カーソル桁 43・行 11+スロット、初期スロット 0。上下で 4 スロットを循環（空スロットにも止まる）。空スロットで決定しても無視。キャンセルで取消。HP 0 のメンバーも選べる。

## 7. 行動順の決定

1. 各戦闘者 a（0〜8）の「速さ」を決める:
   - 生存していない、または状態に麻痺か眠り（状態 AND 0x12 ≠ 0）がある → −1、このラウンドの行動可能フラグ = 偽。
   - それ以外 → パーティは戦闘すばやさ、敵はすばやさ。行動可能フラグ = 真。
2. 行動順を 0,1,…,8 で初期化する。
3. 位置 i = 0〜8 の順に: 位置 i 以降で速さが 0 以上の最大のものを探す（同じ最大値が複数あれば**最も後ろの位置**のもの）。見つかれば、位置 i とその位置の内容（速さと戦闘者番号の両方）を**入れ替える**。見つからなければ（残りがすべて −1）なにもしない。
   - これは「交換方式の選択ソート（降順）」で、同速の扱いや −1 の者の並びは、この交換の結果に従う。
4. 位置の組 (0,1), (2,3), (4,5), (6,7) の順に、それぞれ**乱数を1回引き**、16000 未満なら組の2つを入れ替える。乱数は必ず 4 回引く。

## 8. 手番の処理

行動順の位置 0〜8 について、その戦闘者番号を X とする（後述の反撃で 0xFF に書き換えられた位置は、だれも行動しない）。

行動回数 = 1。ただし X が敵で、特性フラグ 0x80 が立っていれば 2。次を行動回数だけ繰り返す（途中の「打ち切り」はその戦闘者の残り行動回数もすべて捨てる）。

1. X が生存していなければ打ち切り。
2. X が眠っていれば**乱数を1回引き**、8000 未満なら: 眠りを解除、ステータス更新、「X の名前」+「は目を覚ました！;@」を出力して打ち切り。（眠っていなければ乱数は引かない）
3. X が混乱していれば**乱数を1回引き**、8000 未満なら: 混乱を解除、ステータス更新、「名前」+「は正気に戻った！;@」を出力して打ち切り。
4. 麻痺か眠りの状態にある、またはこのラウンドの行動可能フラグが偽なら打ち切り。
5. X が敵で隠れ中なら打ち切り。
6. 行動を決める（パーティは §9、敵は §10）。これで「現在の行動」「現在の対象」が決まる。
7. 「X の名前」を出力する（以降のメッセージはこの後に続く）。
8. 分岐:
   - X がパーティで行動が「逃げる」: 「は逃げ出した！_」を出力。結果 = 逃走、BGM をフィールド BGM に戻す要求、後始末（§17.4）して戦闘終了。**逃走は必ず成功する**（成功判定はない）。
   - X がパーティで行動がアイテム（32 以上）: アイテム使用（§14）。
   - 行動が 0〜31: 魔法を唱える（§13）。
   - それ以外: 行動実行（§12）。
9. X が敵で、行動が「身構える」「じっとしている」以外なら、X の身構え中フラグを下ろす。
10. 「@」を出力する（キー入力待ち → メッセージ消去）。
11. 全滅判定: 「生存していて麻痺していない」パーティメンバーが1人もいなければ全滅（§17.2）。
12. 勝利判定: 生存している敵が1体もいなければ（隠れ中の敵も生存に数える）勝利（§17.1）。全滅判定が先。

補足:
- 眠り・混乱からの回復判定は、その戦闘者の位置の手番が来たときに 1 ラウンド 1 回（2 回行動の敵は各回）行われ、回復した手番は行動しない。
- ラウンド開始時に麻痺・眠り・死亡だった者は、ラウンド中に治っても・生き返ってもそのラウンドは行動できない。
- 麻痺には時間経過の回復がない（魔法 7・アイテム種類 10 のみ）。封印にも戦闘中の自然回復はない。

## 9. パーティの行動決定（自動行動を含む）

スロット s の行動を決める。

### 9.1 入力どおりに行動する場合

入力済みコマンドが「自動戦闘」でなく、かつ s が混乱していない場合:
1. 現在の行動 = 入力済みコマンド、現在の対象 = 入力済み対象。
2. 行動が通常攻撃で、対象が生存していなければ、対象を「ランダム対象選択」（§11.1）で選び直す。
3. 終わり。

（魔法・アイテムの対象が死んでいる場合の扱いは §13.1 の対象確認で行う。）

### 9.2 自動行動（自動戦闘、または混乱中）

以下で「攻撃陣営」は §11.1 の規則で決まる陣営（通常は敵側、混乱中はパーティ側）、「自陣営」はその反対。混乱中のメンバーは自陣営が敵側になるため、**敵を治療し、仲間を攻撃する**。

「詠唱可能」の条件（この自動行動専用）: その魔法を習得済み（習得レベル ≤ レベル）、かつ 現在MP ≥ 消費MP、かつ **現在MP ÷ 4（切り捨て）≥ 消費MP**。

1. s が封印状態なら: 対象 = ランダム対象選択、行動 = 通常攻撃。終わり。
2. 対象 = 「自陣営で麻痺している者のうち最後の者」（§11.4）。いて、魔法 7 が詠唱可能なら 行動 = 魔法 7。終わり。
3. 対象 = 「自陣営で混乱している者のうち最後の者」。いて、魔法 11 が詠唱可能なら 行動 = 魔法 11。終わり。
4. 対象 = 「自陣営で最も傷ついた者」（§11.2）。魔法 0〜4 のうち詠唱可能な**最大の番号**を探す。対象がいて、そのような魔法があれば 行動 = その魔法。終わり。
5. 対象 = ランダム対象選択。対象がパーティ側（番号 0〜3）なら 行動 = 通常攻撃。終わり。
6. 対象が敵の場合: 見積もりダメージ = s の戦闘攻撃力 − 対象の防御力 ÷ 2（切り捨て）。魔法 20〜30 のうち、次をすべて満たす**最大の番号**を探す: 詠唱可能、対象の魔法有効マスクでその番号のビットが立っている、対象が隠れ中でない、その魔法の威力 ≥ 見積もりダメージ。あれば 行動 = その魔法、なければ 行動 = 通常攻撃。

注意:
- 手順 2〜4 で条件を満たさなかった場合も「現在の対象」は上書きされていく。最終的な対象は最後に代入された値。
- 魔法 0〜4 には全体回復（3, 4）も含まれ、番号の大きいものが優先される。全体回復が選ばれた場合の対象は手順 4 の個人番号だが、全体回復の処理は対象の陣営として扱われる（§13.3 の全体処理は「対象 < 4 ならパーティ側」）。
- 手順 6 の範囲 20〜30 には全体攻撃の 23〜25・29・30 も含まれる（31 は含まれない）。
- 入力時に「戦う」等を選んだメンバーがその後混乱した場合、手番では自動行動になる。逆に、入力時に混乱していて飛ばされ、手番までに混乱が解けたメンバーは、残っていた古い入力済みコマンド（戦闘開始直後なら「魔法0番・対象0」）で行動する。

## 10. 敵の行動選択

### 10.1 行動ビット（40 ビット）

行動ビット番号 n（0〜39）は、その敵が取りうる行動を表す。番号 → 行動と対象の対応:

| 番号 | 行動 | 対象の決め方 | 対象が決まらないとき |
|---|---|---|---|
| 0 | 通常攻撃 | ランダム対象選択 | — |
| 1 | 身構える | （変更しない） | — |
| 2 | 身を隠す | （変更しない） | — |
| 3 | 逃げ出す | （変更しない） | — |
| 4 | 突撃 | ランダム対象選択 | — |
| 5 | 自爆 | 攻撃陣営（陣営値） | — |
| 6 | MP を奪う | 攻撃陣営で MP 最多の者（§11.5） | （再抽選しない） |
| 7 | じっとしている | （変更しない） | — |
| 8, 9, 10 | 魔法 0, 1, 2（単体回復） | 自陣営で最も傷ついた者 | 再抽選 |
| 11, 12 | 魔法 3, 4（全体回復） | 自陣営（陣営値） | — |
| 13 | 魔法 5（消える） | （変更しない＝直前の値のまま） | — |
| 14 | 魔法 6（蘇生） | 自陣営で最後の倒れた者（§11.3） | 再抽選 |
| 15 | 魔法 7（治療） | 自陣営で毒か麻痺の者のうち最後の者 | 再抽選 |
| 16 | 魔法 8（毒） | 攻撃陣営で、状態 0x1B（毒・麻痺・混乱・眠り）のどれもない者をランダムに | 再抽選 |
| 17 | 魔法 9（麻痺） | 攻撃陣営で、状態 0x1A（麻痺・混乱・眠り）のない者をランダムに | 再抽選 |
| 18 | 魔法 10（封印） | 攻撃陣営で、状態 0x1E（麻痺・封印・混乱・眠り）のない者をランダムに | 再抽選 |
| 19 | 魔法 11（混乱） | 攻撃陣営で、状態 0x1A のない者をランダムに | 再抽選 |

| 34, 35, 36 | 魔法 26, 27, 28（単体攻撃） | ランダム対象選択 | — |
| 37, 38, 39 | 魔法 29, 30, 31（全体攻撃） | 攻撃陣営（陣営値） | — |

「攻撃陣営」「自陣営」は §11.1 による（通常の敵は攻撃陣営 = パーティ側、自陣営 = 敵側）。

### 10.2 特性フラグ（1 バイト）

| ビット値 | 意味 |
|---|---|
| 0x01 | 半々で失敗: 通常攻撃（突撃・反撃を含む、この敵が攻撃側のとき）の最後に乱数を1回引き 16000 未満ならダメージ 0。魔法を唱えるとき最初に乱数を1回引き 16000 未満なら失敗 |
| 0x02 | 痛恨の一撃が出やすい（判定のしきい値 2000 → 20000） |
| 0x04 | 攻撃陣営を敵側にする（味方の敵を攻撃し、パーティを回復する） |
| 0x08 | 行動決定後、対象を常に自分自身にする |
| 0x10 | 能力上昇魔法（行動ビット 22〜24）の対象を自分自身にする |
| 0x20 | 魔法威力強化: 威力 = 乱数幅付け（min(威力×2, 9999)） |
| 0x40 | 倒されてもラウンド終了時に復活することがある（§16） |
| 0x80 | 1 手番に 2 回行動する |

### 10.3 選択手順

選択位置 = 0、試行回数 = 0 で始める。

1. 試行回数を 1 増やす。
2. 行動ビット 5 バイトの論理和が 0 でなければ:
   1. **乱数を1回引き**、40 で割った余りを m とする。
   2. 次を m+1 回繰り返す: 選択位置を (選択位置+1) mod 40 に進め、そのビットが立っている番号に当たるまで進め続ける。当たった番号が 0 なら、**乱数を1回引き** 3000 未満なら繰り返しをここで打ち切る（番号 0 以外に当たったときは乱数を引かない）。
   - 行動ビットがすべて 0 なら選択位置は 0（通常攻撃）のまま、乱数も引かない。
   - 選択位置は試行をまたいで引き継ぐ（再抽選は直前の選択位置の続きから進む）。
3. 選択位置の番号に応じて §10.1 の表で行動と対象を決める（対象の決め方で乱数を引くことがある）。
4. 「再抽選」の行で対象が決まらなかった（該当者なし）場合: 試行回数が 10 を超えていれば 行動 = じっとしている（対象は変更しない）として終わる。そうでなければ手順 1 へ戻る。
5. 特性フラグ 0x10 が立っていて選択位置が 22〜24 なら、対象 = 自分。
6. 特性フラグ 0x08 が立っていれば、対象 = 自分（どの行動でも。通常攻撃なら自分を攻撃する）。

注意（そのまま再現すること）:
- 行動ビット 13（魔法 5）は対象を設定しないので、直前に「現在の対象」に入っていた値（前の戦闘者の行動の対象など）がそのまま残る。効果は対象に関係しない。
- 行動ビット 6（MP を奪う）で攻撃陣営が敵側の場合（特性 0x04 や混乱）、MP 最多の者は「なし（−1）」となるが、再抽選されずにそのまま行動する。【未確認】この場合の原作の挙動（参照実装では範囲外の参照となり未定義）。推奨: §12.12 を次のように実行する — 乱数幅付け(10) の乱数 2 回は引く、だれの MP も減らさない、対象の名前は空文字として「はＭＰを{量} p.奪われた！;」を出力し、ステータス更新（パーティ側の対象と同じくステータスウィンドウを描き直す。見た目は変わらない）を行う（v1.1 で追記）。

## 11. 対象選択の規則

### 11.1 攻撃陣営とランダム対象選択

**攻撃陣営**:
- パーティメンバー: 通常は敵側（4）。混乱中はパーティ側（0）。
- 敵: 特性フラグ 0x04 があれば敵側（4）、なければパーティ側（0）。混乱中はこれを反転する。
- 「自陣営」= 4 − 攻撃陣営。

**ランダム対象選択**（行動者の攻撃陣営から1人選ぶ）:

攻撃陣営が敵側の場合:
1. 「敵側で最も傷ついた者」（§11.2）がいればそれ。乱数は引かない。
2. いなければ（全員無傷）**乱数を1回引き**、5 で割った余り + 4 を候補とする。候補が「生存していて、かつ（隠れ中でない、または既に 5 回以上候補を進めた）」なら決定。そうでなければ候補を次の敵（4→5→6→7→8→4 の循環）へ進めて繰り返す。

攻撃陣営がパーティ側の場合:
1. **乱数を1回引き**、16 で割った余りで重み表を引く: 余り 0〜9 → スロット 0、10〜14 → スロット 1、15 → スロット 2（スロット 3 は直接は選ばれない）。
2. 選んだスロットが 1 か 2 で、そのメンバーが生存していなければスロット 0 にする。
3. 生存していなければ、生存者に当たるまでスロットを 1 ずつ進める（3 の次は 0）。

（全員が対象外の場合の打ち切りは 参照実装の安全策で、実際には全滅・勝利判定が先に働くため起きない。）

### 11.2 最も傷ついた者

**パーティ側**: 生存メンバーそれぞれについて 比 = 最大HP（記録値）÷ 現在HP（整数除算）を求め、比が 1 より大きい中で最大の者（同じ比なら若いスロット）。つまり HP が最大HP の半分以下の者だけが候補。いなければ「なし」。

**敵側**:
1. 生存していて隠れ中でない敵について 比 = 最大HP ÷ HP（整数除算）。比 > 1 の中で最大の者（同値なら若い番号）。
2. いなければ、同じ候補について 減少量 = 最大HP − HP。減少量 > 0 の中で最大の者（同値なら若い番号）。
3. それもいなければ「なし」。

### 11.3 最後の倒れた者

- パーティ側: スロット 0〜3 のうち、スロットが空（0xFF）でなく HP = 0 の者の最後（最大のスロット番号）。
- 敵側: 最大HP ≠ 0 かつ HP = 0 の敵の最後（最大の番号）。逃げた・消えた敵は含まない。
- いなければ「なし」。

### 11.4 指定状態の最後の者

指定陣営の生存者のうち、状態に指定ビットのいずれかを持つ者の最後（最大の番号）。いなければ「なし」。

### 11.5 MP 最多の者

パーティ側のみ: 生存メンバーのうち現在MP が最大の者（同値なら若いスロット）。敵側を指定したときは「なし」。

### 11.6 指定状態を持たない者をランダムに

- パーティ側: **乱数を1回引き** 4 で割った余りのスロットから始め、スロットを 1 ずつ循環して最大 4 人調べ、「生存していて指定ビットをどれも持たない」最初の者。いなければ「なし」。
- 敵側: **乱数を1回引き** 5 で割った余り + 4 から始め、4→5→…→8→4 と循環して最大 5 体調べる。条件は同じ（隠れ中かどうかは問わない）。

## 12. 行動の実行（通常攻撃と敵の特殊行動）

行動の最初に効果音を鳴らす: 行動者がパーティなら 10 番、敵なら 12 番。以下、「名前」は行動者名がすでに出力された後に続けて出す文字列。

### 12.1 通常攻撃（−1）

1. 「の攻撃！#;」を出力。
2. 対象が敵で隠れ中なら、「対象の名前」+「は隠れている‥‥;」を出力して終わり。
3. ダメージ計算（§12.2）→ ダメージ表示（§12.3）。

### 12.2 ダメージ計算（攻撃側 A、対象 T）

1. 攻撃値 = A がパーティなら戦闘攻撃力、敵なら攻撃力。防御値 = T がパーティなら戦闘防御力、敵なら防御力。
2. d = 攻撃値 − 防御値 ÷ 2（切り捨て）。
3. d < 0 の場合: **乱数を1回引き**、15000 より大きければ d = 0、そうでなければ d = 1。
   d ≥ 0 の場合: d = 乱数幅付け(d)（§12.4）。
4. T がパーティの場合: **乱数を1回引き**、その値が 戦闘運×10 より小さければ d = 0（回避）。
5. T が敵で身構え中なら d = d ÷ 2（切り捨て）。（パーティには身構えがない）
6. 会心判定: しきい値 = A がパーティなら 5000、敵なら 2000、特性フラグ 0x02 の敵なら 20000。**乱数を1回引き**、しきい値未満なら: 「会心」（A がパーティ）または「痛恨」（A が敵）+「の一撃！#」を出力し、d = d + d ÷ 2。
7. A が特性フラグ 0x01 の敵なら **乱数を1回引き**、16000 未満なら d = 0。
8. T の HP を d 減らす（§12.5）。T が生き残れば結果は d、倒れたら −d。

確率の目安（乱数 0〜32767）: 会心 5000/32768 ≈ 15.3%、痛恨 2000/32768 ≈ 6.1%（強化時 20000/32768 ≈ 61%）。d<0 のとき 1 になる確率 15001/32768。

### 12.3 ダメージ表示

結果 v、対象 T（「現在の対象」）について:
1. 「T の名前」+「は」を出力。
2. v = 0 の場合: 効果音 29 番、「攻撃をかわした！#;;」を出力して終わり（0 ダメージはすべて「かわした」と表示される）。
3. |v| を 10 進で出力、「 p.のダメージ！#」を出力。
4. 被弾演出: T が敵なら敵の白点滅（§18.1）、パーティなら画面揺れ（§18.3）。いずれも効果音 22 番を含む。
5. v < 0 なら撃破表示（§12.6）。
6. T がパーティならステータス更新。

### 12.4 乱数幅付け

値 v について:
- v ≤ 3 なら v のまま（乱数を引かない）。
- そうでなければ、**乱数を1回引き** (v ÷ 4) で割った余りを r とし、続けて**乱数をもう1回引き** 16000 未満なら +r、そうでなければ −r。結果 = v ± r。範囲は v − (v÷4 − 1) 〜 v + (v÷4 − 1)。

### 12.5 HP の増減

対象の HP を「d 減らす」（d が負なら回復）:
- d < 0（回復）で対象の HP が 0 なら、なにもせず「倒れている」を返す（回復で生き返らない）。
- HP − d ≤ 0 なら HP = 0 として「倒れた」を返す。（d ≥ 0 で HP 0 の対象を叩いた場合も「倒れた」）
- それ以外は HP = min(HP − d, 上限)。上限はパーティならその場で計算した L×体力+30、敵なら最大HP。「生きている」を返す。

### 12.6 撃破表示

1. 「名前」を出力。
2. パーティなら「は気絶してしまった‥‥」（制御文字なし。後続のメッセージは同じ行に続く）。
3. 敵なら「を倒した！」を出力し、敵の消滅演出（§18.2）。

### 12.7 身構える（0x33）

「は身構えた！;」を出力し、行動者の身構え中フラグを立てる。§8 手順 9 により、身構え・じっとしている以外の行動をするまで（つまり次の自分の行動まで）フラグは残る。身構え中の敵が受ける通常攻撃ダメージは半分。

### 12.8 身を隠す（0x34）

「は身を隠した！;」を出力し、隠れ中フラグを立て、消滅演出（§18.2）で画像を消す。隠れ中の敵は: 行動しない、通常攻撃・単体魔法の対象になると「対象の名前」+「は隠れている‥‥;」で無効（「は隠れている‥‥;」は出る場所によらず常に対象の名前を前置する）（v1.1 で修正）、全体攻撃魔法・全体回復でも飛ばされる（§13.3）、ランダム対象選択で避けられる。ただし敵名一覧・敵選択には表示され、生存として数える。そのラウンドの終了時に再び現れる（§16）。

### 12.9 逃げ出す（0x35）

「は逃げ出した！;」を出力し、その敵の最大HP と HP を 0 にし（戦場から除外、経験値・お金も得られない）、消滅演出。

### 12.10 突撃（0x36）

1. 「が突撃してきた！#;」を出力。
2. 対象への通常攻撃のダメージ計算と表示（§12.2〜12.3。隠れ中の確認はしない）。
3. 対象が倒れていれば終わり。
4. 「対象の名前」+「の反撃！#;」を出力。
5. 突撃した敵の身構え中フラグを立てる（反撃のダメージが半分になる）。
6. 現在の対象 = 突撃した敵とし、元の対象を攻撃側として通常攻撃のダメージ計算と表示を行う（反撃側が麻痺・眠り中でも反撃する。反撃側がパーティなら会心しきい値 5000 等、攻撃側の規則に従う）。
7. 行動順の中の、反撃した者の戦闘者番号をすべて「行動なし（0xFF）」に書き換える（まだ手番が来ていなければ、このラウンドは行動できなくなる）。
8. この後 §8 手順 9 で突撃した敵の身構え中フラグは下ろされる。

### 12.11 自爆（0x37）

1. 「が自爆した！#;」を出力。
2. 自分の HP を 0 にする（最大HP は残るので、倒した扱いで経験値・お金は得られる）。消滅演出。
3. 全体処理（§13.3 の「固定ダメージ」型）: 対象陣営 = 現在の対象（自爆の対象 = 攻撃陣営）、ダメージ量 = 自分の最大HP ÷ 4（切り捨て）。防御・運・乱数は関係しない。

### 12.12 MP を奪う（0x38）

1. 「の攻撃！#;」を出力。
2. 量 = 乱数幅付け(10)（乱数を2回引く。結果は 9, 10, 11 のいずれか）。
3. 対象の MP を量だけ減らす。ただし MP が量に満たなければ**まったく減らさない**。
4. 「対象の名前」+「はＭＰを」+ 量 +「 p.奪われた！;」を出力（減らなかった場合も同じ）。ステータス更新。
   - 対象が「なし（−1）」の場合（§10.3 注意）は 参照実装でも未定義。推奨: 乱数 2 回は引き、MP はだれからも減らさず、名前を空文字として同じ文を出力し、ステータスウィンドウを描き直す（v1.1 で追記）。
5. 奪った MP が敵に入ることはない。

### 12.13 じっとしている（0x39）

「は　じっとしている‥‥;」を出力。

## 13. 魔法

### 13.1 対象確認（パーティが唱える／使う場合のみ）

行動者がパーティのとき、魔法やアイテムの効果を出す前に対象が有効かを確かめる。敵が唱える場合は常に有効。

1. 調べる魔法番号 m: 魔法なら行動の番号。アイテムなら、種類 7〜11 以外は常に有効として終わり。種類 11 なら性能値（**下位 5 ビットに限らない全体**）、種類 7〜10 なら 0。
2. m = 6（蘇生）なら有効。
3. m の対象種別（m の下位 5 ビットで表を引く）が 0 か 4（全体）なら有効。
4. 対象が生存していれば有効。
5. 対象が隠れ中の敵なら「対象の名前」+「は隠れている‥‥;」を出力して無効。
6. それ以外は「対象の名前」+「は」に続けて、敵なら最大HP=0 のとき「いない‥‥#」、そうでなければ「死んでいる‥‥#」。パーティなら「気絶している‥‥」（制御文字なし）を出力して無効。

### 13.2 魔法を唱える（行動者 X、魔法 M、対象 T）

1. 「は#」+ 魔法名（17 バイトを NUL まで）+「の魔法を唱えた！#」を出力。
2. 効果音: M ≤ 7 なら 13 番、それ以外は 20 番。
3. 詠唱フラッシュ（§18.4）。
4. 対象確認（§13.1）を行い、結果を覚えておく。**無効でも次の手順 5 は実行される**（MP は消費され、効果も対象に適用されうる）。
5. 効果処理（§13.4）を行い、結果値 r を得る。
6. X がパーティならステータス更新（MP の減少を表示）。
7. 対象確認が無効、または r が「中断コード」（§13.4 の MP 不足・封印・効かない・隠れている）なら終わり。

9. 結果表示（§13.5）。

### 13.3 全体処理

陣営 S（0 または 4）、量 A、種類 K について、S の戦闘者（パーティ側 0〜3、敵側 4〜8）を番号順に「現在の対象」としながら、生存者だけに次を行う。

- 2 人目以降の処理の前に、K が全体回復（魔法 3, 4）でなければ「@」を出力（キー待ち→消去）。
- K が固定ダメージ（自爆）: 対象が隠れ中の敵なら「対象の名前」+「は隠れている‥‥;」を出力し（名前は §12.1・§13.1 と同じく前置する）（v1.1 で修正）、**全体処理そのものを打ち切る**。そうでなければ対象の HP を A 減らし（§12.5）、ダメージ表示（§12.3）。
- K が魔法 3, 4: 効果処理を「詠唱者なし・量 A」で行う（対象が敵なら魔法耐性マスクと隠れ中の確認が入り、「には効かなかった！#;」等が出ることがある。パーティなら HP を A 回復）。
- K が魔法 23 以上（全体攻撃）: 効果処理を「詠唱者なし・量 A」で行い、中断コードでなければダメージ表示。
- 終わったら現在の対象 = S。

量 A は全員に同じ値（対象ごとの乱数幅はない）。

## 17. 決着と後始末

### 17.1 勝利

1. 「敵を全滅させた！#」を出力。
2. BGM をフィールド BGM に戻す要求（フェードアウト約 320 ms を含む）。
3. 合計経験値・合計お金 = 最大HP ≠ 0 の敵（倒した敵。逃げた・消えた敵は除く）の経験値・お金の和。
4. 「経験値をそれぞれ 」+ 合計経験値 +「p.獲得！#」、「お金を 」+ 合計お金 +「 手に入れた！_」を出力（最後でキー待ち→消去）。
5. スロット 0〜3 の順に経験値加算（§17.1.1）。レベルが上がったら「名前」+「はレベル」+ 新レベル +「になった！_」。
6. 所持金に合計お金を加える（0〜99999999 に収める）。
7. 結果 = 勝利で後始末。

アイテムのドロップはない。経験値は分配せず、**生存している各メンバーに合計値をそのまま**与える。

#### 17.1.1 経験値加算とレベルアップ

- 空スロット・HP 0 のメンバーは対象外（なにも起きない）。
- 経験値（「現レベルでの累積」）に合計経験値を加える。
- 経験値 ≥ 必要経験値(現レベル) である間、次を繰り返す: レベルを 1 上げる（99 なら上げない）、経験値から必要経験値(上げる前のレベル) を引く。1 回でも上がれば最後のレベルを「新レベル」として報告（複数レベル上がっても表示は 1 回）。
- レベル 99 では経験値が引かれ続けるがレベルは変わらない（その場合も「レベル99になった」と表示される）。
- 必要経験値(L): L < 20 なら 10 から始めて L−1 回「×3÷2（切り捨て）」した値、L ≥ 20 なら (L−20)×10000 + 22168。
  - L=1〜19: 10, 15, 22, 33, 49, 73, 109, 163, 244, 366, 549, 823, 1234, 1851, 2776, 4164, 6246, 9369, 14053
  - L=20: 22168、L=21: 32168、…
- レベルアップ時の能力値表示や HP/MP の回復はない（最大値は式で決まるので自動的に増える）。

### 17.2 全滅

1. 「全滅してしまった‥‥_」を出力。
2. 結果 = 全滅で後始末。BGM は戦闘 BGM のまま。
3. 呼び出し側（ランダム・イベントとも）はゲームオーバー判定（→11 章）を行う。判定は「有効メンバーの HP 合計が 0、または麻痺していないメンバーが 0 人」。戦闘の全滅判定は「生存していて麻痺していない者が 0 人」なので食い違いがありうる。例: A が戦闘不能（HP 0・麻痺なし）、B が麻痺（HP > 0）→ 戦闘では全滅だが、ゲームオーバー判定は A を「麻痺していない」と数えるためゲームが続行する。そのまま再現すること。

### 17.3 逃走

§8 手順 8 の通り。結果 = 逃走。イベント戦闘ならイベントの残りを飛ばす。

### 17.4 後始末（全結果共通）

1. パーティの有効スロットの各キャラクターの状態を「毒・麻痺だけ残す」（AND 0x03）。封印・混乱・眠りは解ける。
2. グラフィック画面全体を色 14 で塗る。
3. フィールドのパレット（PALET.DAT）を現在のパレットモード・明るさ補正 0 で設定する（→11 章）。

6. 戦闘用の作業状態を捨てる。

戦闘中に変わった HP・MP・状態（毒・麻痺）・経験値・レベル・所持品・所持金は保持される。

## 19. メッセージの出し方の例

本文は 19 章参照。行動者名の直後に連結される。`#` は改行、`;` は 200 ms 待ち、`@` `_` はキー待ち＋消去。

- 通常攻撃（命中）: 「スライム」「の攻撃！#;」「勇者」「は」「12」「 p.のダメージ！#」→（揺れ）→ 手番末の「@」。
- 会心: 「勇者」「の攻撃！#;」「会心」「の一撃！#」「スライム」「は」「18」「 p.のダメージ！#」→（白点滅）→ 倒したら「スライム」「を倒した！」→（消滅）→「@」。
- 回避: 「…は」「攻撃をかわした！#;;」。
- 魔法: 「魔道士」「は#」「ファイア」「の魔法を唱えた！#」→（効果音・フラッシュ）→ 結果表示。
- MP 不足: 「…は#」「…の魔法を唱えた！#」「ＭＰが足りない！#;」。
- 封印: 「…の魔法を唱えた！#」「しかし、魔法は封じられている！#;」。
- 効かない: 「…の魔法を唱えた！#」「スライム」「には効かなかった！#;」。
- 全体攻撃: 「ＡはN p.のダメージ！#」→「@」→「ＢはN p.のダメージ！#」→ … →（手番末）「@」。
- 勝利: 「敵を全滅させた！#」→（BGM 切替）→「経験値をそれぞれ 」「30」「p.獲得！#」「お金を 」「12」「 手に入れた！_」→「勇者」「はレベル」「3」「になった！_」。
- 全滅: 「全滅してしまった‥‥_」。
- 逃走: 「勇者」「は逃げ出した！_」。

## 20. 乱数を引く順序のまとめ

乱数は 1 系列のみ（→01 章）。戦闘開始時にフレームカウンタ下位 16 ビットで種付けし直す。以下の順序・回数を厳密に守ること。

1. 戦闘開始: ランダムエンカウントかつ敵が 2 体以上のグループ → 1 回（間引き、mod 8）。
2. 各ラウンド:
   1. コマンド入力: なし。
   2. 行動順: 4 回（隣接組の入れ替え判定）。
   3. 行動順の各位置について（2 回行動の敵は各回）:
      1. 眠り中なら 1 回（目覚め）。目覚めなかった場合、混乱中なら 1 回（正気）。目覚めた場合は混乱判定をしない。
      2. 行動決定:
         - パーティ（入力どおり）: 通常攻撃で対象が死んでいればランダム対象選択（パーティ側を狙うなら 1 回、敵側なら「最も傷ついた者」がいなければ 1 回）。
         - パーティ（自動）: 封印中はランダム対象選択。そうでなければ手順 2〜4 が不成立のときに 1 度だけランダム対象選択。
         - 敵: 各試行で〔行動ビットがあれば 1 回（mod 40）＋番号 0 に当たるたびに 1 回〕＋ 対象決定の乱数（ランダム対象選択 0〜1 回、「状態のない者をランダムに」1 回）。再抽選は最大 11 試行。
      3. 行動実行:
         - 通常攻撃（突撃・反撃も同じ）: 〔d<0 なら 1 回／d>3 なら 2 回（乱数幅）〕→〔対象がパーティなら 1 回（運）〕→ 1 回（会心）→〔攻撃側が特性 0x01 の敵なら 1 回〕。突撃は 突撃側の攻撃 →（対象生存時）反撃側の攻撃 の順。
         - MP を奪う: 2 回。自爆・身構え・隠れ・逃げ・じっと: 0 回。
         - 魔法（唱える）: 〔特性 0x01 の敵なら 1 回〕→〔特性 0x20 の敵で威力×2 が 4 以上なら 2 回〕→〔魔法 13 なら 1 回〕。全体処理中の各対象では引かない。特性 0x01 で失敗した場合、および MP 不足・封印・効かない・隠れている で中断した場合（§13.4 の前処理と魔法耐性の確認）は、その時点で終わり以降の乱数は引かない。特性 0x20 の 2 回は魔法番号によらず（回復・補助魔法でも）引く。
         - アイテム: 所持していて対象確認が有効なら、性能値 > 3 のとき 2 回（乱数幅）。魔法アイテムで魔法 13 ならさらに 1 回。
   4. ラウンド終了: 隠れ中で生存していない敵（他に見えている生存敵がいる場合）ごとに 1 回 → 特性 0x40 の倒された敵ごとに 1 回。

注意: 魔法を唱える場合、対象確認が無効でも効果処理（とその乱数）は実行される。

## 受け入れテスト観点

1. **敵配置**: 敵が k 体のとき、左端 X が §3 手順 8 の式どおり（k=5: 16,144,272,400,528 / k=3: 144,272,400 / k=1: 272）、Y=128。サンプル `dm` でグループ 1 の戦闘を起こし（参照実装のヘッドレス実行器の戦闘開始オプションで。これはランダムエンカウント扱いなので間引きで 2 体になることもある）、敵 3 体なら 144, 272, 400 に並ぶこと。
2. **画面**: 背景色 14（PALET2 による。`dm` では青）、敵表示域 y 90〜237 が色 0、下部 3 窓が x 0〜159 / 160〜335 / 336〜639、y 240〜383。ステータス見出し「HP· MAX MP」が (520,248)。
3. **スライドイン**: 戦闘開始から VSYNC 16 回で表示開始ラインが 0 に戻ること。「敵と遭遇した！」が見えた後に消えること。
4. **間引き**: イベント戦闘ではグループの全敵が出る。ランダムでは 5 体グループで 5/8 の確率で 4 体になる（多数回試行で統計確認）。1 体だけのグループは必ず 1 体出る。
5. **行動順**: 全員の速さを手で設定し、§7 の交換式ソートと 4 回の入れ替え乱数で順序が一致すること（同速は後ろの者が先に来ることに注意）。
6. **ダメージ**: 攻撃値 100、防御値 40 → 基本 80、乱数幅 80±(0〜19)。会心で ×1.5（切り捨て加算）。身構え中の敵は半分（会心より前に半減）。防御 ÷2 が攻撃を上回ると 0 か 1。
7. **乱数幅**: v ≤ 3 では乱数を消費しないこと（乱数系列がずれないこと）を、同じ種で戦闘を再生して確認。
8. **0 ダメージ表示**: 運の高いメンバーが回避したとき、効果音 29 と「攻撃をかわした！」が 400 ms 待ちで出ること。
9. **敵 AI**: 行動ビットが番号 0 だけの敵は常に通常攻撃し、行動決定で乱数を「1 回（mod 40）＋番号 0 に当たるたびに 1 回」消費すること。行動ビットが全 0 の敵は乱数を消費せず通常攻撃。
10. **パーティ側ランダム対象**: 敵の通常攻撃がスロット 0 に約 10/16、スロット 1 に 5/16、スロット 2 に 1/16 の頻度で向かい、スロット 3 は前の 3 人が倒れるまで狙われないこと。
11. **魔法耐性**: 魔法有効マスクのビットがない敵に単体魔法 → 「には効かなかった！」。全体攻撃では該当する敵だけ「効かなかった」が出て、他にはダメージ。
12. **MP 不足**: 魔法選択で MP 不足の魔法も選べ、唱えた後に「ＭＰが足りない！」。封印中は MP を消費してから「封じられている」。
13. **自動戦闘**: MP が消費MP の 4 倍未満の魔法は自動では使わないこと。HP が半分以下の仲間がいれば回復魔法（番号が大きいもの優先）。
14. **毒**: ラウンド終了でパーティは 最大HP/20（最低 1）、敵は 最大HP/10（最低 1）減り、HP 1 で止まること。戦闘後も毒・麻痺は残り、封印・混乱・眠りは消えること。
15. **勝利**: 逃げた敵の経験値は入らず、倒した・自爆した敵の分は入ること。HP 0 のメンバーには経験値が入らないこと。必要経験値表（10,15,22,33,…,14053,22168,32168）どおりにレベルアップ。
16. **逃走**: 「逃げる」を選ぶと、パーティの最初の行動可能メンバーの手番で必ず逃走成功。それより前に行動順が来た敵は行動する。イベント戦闘で逃げるとイベントの残りが実行されないこと。
17. **演出時間**: 敵被弾点滅 約 300 ms、消滅 約 344 ms、画面揺れ 約 240 ms、詠唱フラッシュ 約 360 ms。
18. **全滅とゲームオーバーの食い違い**（§17.2 の例）を再現すること。
19. 実データでの確認候補: `dm`, `agasa`, `corpse`, `illusion`, `clock` など D1 サンプル（行動ビット・特性フラグの全ビットが実データ中で使われている。番号 13（魔法5）の使用は少数）。
