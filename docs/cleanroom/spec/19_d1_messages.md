# 19. D1 のシステムメッセージ一覧（RPG.EXE 内蔵文字列）

## この章の範囲

D1 の RPG.EXE が内蔵している（ゲームデータではなくエンジン側が持つ）表示文字列を、用途別に一覧にする。各文字列について「いつ・どこに」表示されるかを添える。ゲームごとに変わる文字列（主人公名・アイテム名・イベントのメッセージ本文など）はデータファイル側にある（10 章）。

表示位置や手順の詳細は 11 章（フィールド・メニュー・イベント）と 12 章（戦闘）を正とし、本章は文字列の正確な中身と出現場所の索引として使う。

## 前提となる他章

- 11_d1_engine.md: メッセージウィンドウの流し込み規則（§7.2）、全角化表示（§3.3）、各メニューの配置
- 12_d1_battle.md: 戦闘メッセージの出る条件
- 01_platform_common.md: SJIS とフォント（外字を含む）

## 0. 表記の約束

- 文字列は「」の中に、表示される文字そのもの（SJIS をデコードした日本語）で書く。文字コードは SJIS（CP932 相当）で、1 バイト文字は半角、2 バイト文字は全角で表示される。
- **半角空白**は文字列の先頭・末尾にあると見えにくいので、表の「注」欄に「先頭に半角空白」などと明記する。全角空白は「　」のまま書く。
- **差し込み**: エンジンが値を連結して表示する箇所を {名前} の形で示す。
  - {名前}: 主人公・敵の名前。データの 17 バイト欄を 0x00 の手前まで（末尾の埋め空白を含む）そのまま。
  - {アイテム名}・{魔法名}: 同上。
  - {数値}: 10 進の半角数字（符号は負のとき '-'）。桁合わせの指定があれば「{数値:右詰め4桁}」（不足分は先頭に半角空白）、「{数値:左詰め2桁}」（不足分は末尾に半角空白）のように書く。
  - 原本では文字列が分割されていて、エンジンが「固定文字列 → 差し込み → 固定文字列」の順に流し込む。本章では連結後の形と、分割された各断片の両方を示す。
- **制御文字**（メッセージウィンドウに流し込む文字列の中だけで意味を持つ。11 章 §7.2）:
  - `#` 改行
  - `;` 200 ミリ秒待つ
  - `@` キー押し待ちのあと文章領域を消去（キー離しは待たない）
  - `_` キー離し待ち・キー押し待ちのあと文章領域を消去
  本章の表では制御文字をそのまま書く（例:「お金が足りません。_」の末尾の `_` は表示されず、キー待ちになる）。
- 「固定表示」とある文字列はメッセージウィンドウを通さず指定位置に直接描くもので、制御文字は解釈されない（`#` などは無い）。「全角化」とあるものは 1 バイト文字を全角に変換して描く（11 章 §3.3）。
- 「バイト数」はメニュー項目など固定幅の文字列について SJIS でのバイト数（＝半角桁数）。

プロンプト枠（11 章 §3.7）に「※」を前置して固定表示する。多くは窓 (0x32,1)–(0x4D,3)、文字は (0x34,2)。

| 文字列 | いつ |
|---|---|
| 「※」 | すべてのプロンプトの先頭に付く印 |
| 「アイテムの選択」 | アイテムメニューで所持品一覧を出すとき |
| 「魔法の選択」 | 魔法メニューで魔法一覧を出すとき |
| 「だれが使いますか？」 | 魔法メニューで唱える人を選ぶとき |
| 「だれに使いますか？」 | 回復アイテム（種類 7–10）や対象を取る魔法（0,1,2,6,7）の対象を選ぶとき |

| 「先頭の主人公キャラを」 | 並び替えの 1 番目を選ぶとき |
| 「２番目の主人公キャラを」 | 並び替えの 2 番目 |
| 「３番目の主人公キャラを」 | 並び替えの 3 番目 |

### 5.5 状態表示

主人公の状態を 1 語で示す。全角空白 1 個 + 1 文字（4 バイト）。パーティ状態ウィンドウ、ステータス画面、装備の主人公一覧、戦闘のステータス窓に固定表示する。複数当てはまるときは表の下の行ほど優先（11 章 §3.9）。

| 文字列 | 状態 |
|---|---|
| 「　毒」 | 毒（状態 0x01） |
| 「　封」 | 魔法封じ（0x04、戦闘中のみ） |
| 「　乱」 | 混乱（0x08、戦闘中のみ） |
| 「　眠」 | 睡眠（0x10、戦闘中のみ） |
| 「　ﾏﾋ」 | 麻痺（0x02）。「ﾏﾋ」は半角カナ 2 文字 |
| 「　〈EBC0〉」 | HP 0（戦闘不能）。2 文字目は SJIS コード 0xEBC0（JIS 0x7642、PC-98 の外字領域）。字形は【未確認】（原本が外字として定義している可能性。01 章参照） |

### 5.10 並び替え

選んだ順番の印として「１」「２」「３」「４」を (0x19, 4+枠) に描き、取消で戻るときは全角空白で消す。エンジンは半角の「1」〜「4」と「 」を全角化して描く（内蔵文字列表には全角の「１」〜「４」も別にあるが、結果は同じ字形）。

## 6. フィールドでの魔法・アイテム使用のメッセージ

いずれも窓 (0x10,0xA)–(0x3F,0xE) の文章領域（原点行 0xB）に流し込む（11 章 §9.6）。

| 連結後 | 断片 | いつ |
|---|---|---|
| 「ＭＰが足りない！_」 | 同左 | 唱える人の MP が消費 MP に足りないとき |
| 「{名前}は#{魔法名}の魔法を唱えた！#」 | 「は#」、「の魔法を唱えた！#」 | 魔法を唱えたとき（MP 消費後） |
| 「{アイテム名}を使った！#」 | 「を使った！#」 | アイテムを使ったとき（魔法アイテムを含む） |
| 「{名前}のＨＰが{回復量} p.回復した！_」 | 「のＨＰが」、「 p.回復した！_」（先頭に半角空白） | 単体 HP 回復の魔法（0–2）・HP 回復アイテムが効いたとき |
| 「{名前}のＭＰが{回復量} p.回復した！_」 | 「のＭＰが」、「 p.回復した！_」 | MP 回復アイテムが効いたとき |
| 「ＨＰがそれぞれ{回復量} p.ずつ回復した！_」 | 「ＨＰがそれぞれ」、「 p.ずつ回復した！_」（先頭に半角空白） | 全体 HP 回復の魔法（3, 4） |

## 受け入れテスト観点

1. 各文字列を SJIS（CP932）で符号化したバイト列が、表記どおりの文字・空白で構成されていること（特に先頭・末尾の半角空白、全角空白の数、メニュー項目のバイト数）。
2. 制御文字の位置: 「お金が足りません。_」でキー待ち後に消去、「の毒が消えた！#」で改行、「は隠れている‥‥;」で 200 ミリ秒待ちになること。
3. 宿屋のメッセージが 2 行目から始まり「宿泊料金は{料金} です。泊まりますか？」と表示されること。
4. 名前の差し込みで 16 バイトの埋め空白がそのまま表示されること（例: 名前「メガディス」＋空白 6 個 のあとに「は#」）。
5. 全角化表示: ステータス画面の「ＨＰ　　　６０／」「ｍａｘ　　　６０」（HP 60 の場合。書式中の空白 1＋桁合わせの空白 2 が全角空白 3 個になる）、所持金「Ｇ／　　　　　２０９」などが全角で並ぶこと。
6. デバッグキーを押しながらシステムメニューを開いたときだけ「ゲーム進行モニタ」が出ること。
