# Questions for the Spec (D2: Chapters 20 and 21)

All answered by v1.1 (D2F-Q1–Q12 in `spec-answers-v1.1.md`).

| No. | Chapter/section | Question | v1.1 answer and implementation | Status |
|---|---|---|---|---|
| Q1 | 21 §5.6 | In "event value on the same layer as the hero" (主人公と同じ層のイベント値), is the "chip underfoot" (足元チップ) the chip under the hero or the chip at the queried position? | The chip at the queried position. Same as the provisional implementation | Resolved |
| Q2 | 21 §7.4 / 22 §6.6 | Is the hero's display-direction lock cleared at event end? (contradiction) | Chapter 22 is correct. It is not cleared (chapter 21 corrected). Same as the provisional implementation | Resolved |
| Q3 | 21 §2.4 / 22 §6.8 | Is the 1-VSYNC wait also performed when re-applying the color tone with speed −1? | Always wait. Same as the provisional implementation | Resolved |
| Q4 | 20 §8.5 | When a BKG file is smaller than 41008 bytes. | No image (draw nothing and do not change the palette). Changed `loadBattleBg` to return false | Resolved |
| Q5 | 20 §8.3 | When an EGD is smaller than the specified size. | The missing part is 0. Same as the provisional implementation | Resolved |
| Q6 | 20 §7.3.1 | When the map size N is not one of the 9 levels. | File offsets use the raw N (0x2C+N×N); in memory N is clamped to 1–160 (N = 0 becomes 1). Clamped in `MapData::n()` | Resolved |
| Q7 | 21 §5.5 | Animation type 4 or higher. | Same as type 3. Same as the provisional implementation | Resolved |
| Q8 | 21 §9.4 | Matching an SJIS BGM name against a UTF-8 file name. | Accepted as an improvement (OpenDante98's reference output is silent, so the audio of that scene does not match) | Resolved |
| Q9 | 01 §9.2 | Scope of "only once" for `--battle`. | Once per program run. Same as the provisional implementation | Resolved |
| Q10 | 21 §3.3 | STOP check in the key wait after the title image. | Disabled. Same as the provisional implementation | Resolved |
| Q11 | 01 §9.2 | How many times `--gold`/`--item`/`--warp` are applied. | Every time a new game is started (not applied on continue). Changed | Resolved |
| Q12 | 20 §7.3 | Map version of a map file truncated before the version field. | No initial value. Only the bytes present in the file are overwritten; the rest keep the previous map's values. Loading is byte-wise. Changed | Resolved |

## Optional extensions in v1.1

- 01 §4.3 ROLL UP / ROLL DOWN: added `rollUp` / `rollDown` to `core::InputState`. SDL maps them to PageUp / PageDown,
  headless scripts to `p` / `n`. The D2 key buffer queues ROLL UP (0x36) and then ROLL DOWN (0x37) after the 6 keys, using the same rules.
